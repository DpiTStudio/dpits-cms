# Глобальные шаблоны (`templates/`)

Папка содержит HTML-шаблоны, используемые во всём проекте. Каждое приложение имеет собственную подпапку. Базовый шаблон — `base.html`.

---

## 📁 Структура

```
templates/
├── base.html               # Базовый шаблон всех страниц
├── header.html             # Шапка сайта
├── header_menu.html        # Навигационное меню
├── hero.html               # Hero-баннер
├── footer.html             # Подвал
├── breadcrumbs.html        # Хлебные крошки
├── sidebar.html            # Обёртка сайдбара
├── content-section.html    # Секция контента
├── featured_pages.html     # Блок рекомендуемых страниц
├── news_b.html             # Блок последних новостей (главная)
├── portfolio_b.html        # Блок последних работ (главная)
├── cart_drawer.html        # Выдвижная панель корзины услуг
├── social-share.html       # Кнопки шаринга
├── css.html                # Подключение CSS-файлов
├── js.html                 # Подключение JS-файлов
├── robots.txt              # Шаблон robots.txt
├── content_sidebar/        # Виджеты боковой колонки
│   ├── cs_news_sidebar.html     # Последние новости
│   ├── cs_contacts_sidebar.html # Контактная информация
│   └── ...                      # Другие виджеты
├── bg_cont/                # Фоновые контейнеры
├── includes/               # Повторно используемые фрагменты
└── admin/                  # Переопределения шаблонов Admin
```

---

## 📄 Описание шаблонов

### `base.html` — Базовый шаблон
Основа всех страниц. Определяет:
- Базовую HTML-структуру (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- SEO мета-теги (`title`, `description`, `keywords`, Open Graph)
- Подключение глобальных CSS (`{% include "css.html" %}`)
- Подключение глобальных JS (`{% include "js.html" %}`)
- Блоки для переопределения в дочерних шаблонах:
  - `{% block title %}` — заголовок страницы
  - `{% block content %}` — основное содержимое
  - `{% block extra_css %}` — дополнительные стили
  - `{% block extra_js %}` — дополнительные скрипты
- Подключение компонентов: header, footer, breadcrumbs

---

### `header.html` — Шапка сайта
- Логотип (изображение или текст из `site_settings`)
- Контактная информация (телефон, email, адрес)
- Ссылки на соцсети
- Кнопка корзины услуг

---

### `header_menu.html` — Навигационное меню
- Горизонтальная навигация с выпадающими подменю
- **Glassmorphism** эффект на dropdown-меню
- Адаптивное мобильное меню (Burger)
- Активный класс для текущей страницы
- Пункты формируются из `menu_pages` (context processor)

---

### `hero.html` — Hero-баннер
Полноэкранный баннер с:
- Фоновым изображением из `HeroMixin`
- Заголовком и подзаголовком
- Overlay для читаемости текста
- Поддержкой кастомных настроек для каждой страницы

---

### `footer.html` — Подвал сайта
- Название компании и слоган
- Контактные данные (телефон, email, адрес)
- Ссылки на разделы сайта
- Иконки социальных сетей (из `SiteSettings.get_social_links()`)
- Год и копирайт

---

### `breadcrumbs.html` — Хлебные крошки
Компонент навигации «хлебные крошки». Принимает переменную `breadcrumbs` из контекста вида:
```python
[{"title": "Новости", "url": "/news/", "icon": "fas fa-newspaper"}, ...]
```

---

### `sidebar.html` — Боковая колонка
Обёртка для виджетов сайдбара. Включает виджеты из `content_sidebar/`.

---

### `content_sidebar/` — Виджеты сайдбара

| Файл | Описание |
|------|----------|
| `cs_news_sidebar.html` | Последние новости с изображениями (glassmorphism) |
| `cs_contacts_sidebar.html` | Контактная информация и ссылки на соцсети |

---

### `content-section.html` — Секция контента
Структурный блок для оформления разделов страницы.

---

### `news_b.html` — Блок новостей на главной
Отображает `recent_news_list` (3 последние активные новости) на главной странице.

---

### `portfolio_b.html` — Блок портфолио на главной
Отображает `recent_portfolio_list` (3 последние опубликованные работы) на главной странице.

---

### `cart_drawer.html` — Корзина услуг
Выдвижная боковая панель корзины (slide-in drawer) с:
- Списком добавленных услуг
- Возможностью удаления
- Общей суммой
- Кнопкой оформления

---

### `social-share.html` — Кнопки шаринга
Кнопки для публикации текущей страницы в социальных сетях.

---

### `css.html` — Подключение стилей
Централизованное подключение всех CSS-файлов проекта:
- Bootstrap (или кастомная сетка)
- Font Awesome (иконки)
- Google Fonts (шрифты)
- Кастомные стили приложений
- `animations.css` (micro-анимации)

---

### `js.html` — Подключение скриптов
Централизованное подключение JS в конце `<body>`:
- Основные скрипты проекта
- Скрипты поиска (живой поиск)
- Скрипты корзины
- Инициализация компонентов

---

### `robots.txt` — Правила для роботов
Шаблон для файла `/robots.txt`. Содержит правила для поисковых роботов (разрешённые и запрещённые пути).
