# 🎨 Приложение Portfolio (Портфолио)

Мощный модуль для демонстрации выполненных работ, управления клиентами и ведения заказов.

## 🚀 Функционал

*   **Портфолио работ**: Детальные кейсы с описанием, технологиями и изображениями.
*   **Управление клиентами**: База данных заказчиков с привязкой к работам.
*   **Система заказов (CRM)**: Внутренняя система для ведения заказов клиентов, отслеживания статусов, бюджетов и дедлайнов.
*   **Интеграция с новостями**: Автоматическая публикация новости при добавлении новой работы в портфолио.
*   **Отзывы к работам**: Возможность оставлять отзывы к конкретным проектам.

## 🗄 Основные модели

### `PortfolioItem` (Работа)
*   Описание проекта, используемые технологии.
*   Ссылки на живой проект и репозиторий (GitHub).
*   Статусы: Черновик / Опубликовано / Архив.
*   Привязка к клиенту и категории.

### `Client` (Клиент)
*   Профиль заказчика.
*   Связь с пользователем сайта (User).
*   Контактные данные, компания.

### `Order` (Заказ)
*   Полноценная сущность заказа.
*   Статусы: Новый, В работе, Завершен, Отменен.
*   Приоритеты: Низкий, Средний, Высокий, Срочный.
*   Бюджет, дедлайн, файлы требований.

### `OrderMessage` (Сообщения заказа)
*   Переписка в рамках заказа между клиентом и администратором.
*   Поддержка вложений файлов.

### `PortfolioCategory` (Категории)
*   Классификация работ (например, "Веб-сайты", "Мобильные приложения").
