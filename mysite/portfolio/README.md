# Приложение `portfolio` — Портфолио и CRM

Модуль управления портфолио выполненных работ (кейсов) компании, ведения базы клиентов, отслеживания заказов с интерактивным чатом и сбора премодерируемых проектных отзывов.

---

## 📁 Структура файлов

```
portfolio/
├── models.py           # Модели: Client, PortfolioCategory, PortfolioItem, Order, OrderMessage, PortfolioReview
├── views.py            # Представления
├── urls.py             # URL-маршруты
├── admin.py            # Конфигурация Django Admin
├── apps.py             # Конфигурация приложения
├── forms.py            # Формы (создание заказов, отправка отзывов)
├── utils.py            # Вспомогательные функции (загрузка файлов)
├── migrations/         # Миграции базы данных
└── templates/portfolio/# HTML-шаблоны
```

---

## 📦 Модели (`models.py`)

### `Client` — Клиент / Заказчик
Расширенный профиль пользователя-заказчика, связанный с базовой моделью `User`.

| Поле | Тип | Описание |
|------|-----|----------|
| `user` | OneToOneField→User | Связанный аккаунт Django (CASCADE) |
| `company` | CharField(200) | Название компании заказчика |
| `phone` | CharField(20) | Номер телефона |
| `website` | URLField | Адрес веб-сайта |
| `description` | CKEditor5Field | Описание/информация о клиенте |
| `is_verified` | BooleanField | Подтвержден ли статус клиента (по умолчанию: False) |

---

### `PortfolioCategory` — Категория портфолио
Категории проектов с поддержкой Hero-баннеров и SEO-полей. Наследует `HeroMixin`.

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | CharField(100) | Название категории |
| `image` | ImageField | Главное изображение категории |
| `slug` | SlugField | Уникальный URL (автогенерация из name) |
| `description` | CKEditor5Field | Описание категории |
| `order` | IntegerField | Порядок отображения (чем больше, тем выше) |
| `is_active` | BooleanField | Флаг активности |
| `seo_*` | CharField | SEO-метатеги (title, description, keywords) |

---

### `PortfolioItem` — Работа портфолио
Проект (кейс) компании. Наследует `HeroMixin`.

| Поле | Тип | Описание |
|------|-----|----------|
| `title` | CharField(200) | Название проекта |
| `slug` | SlugField | Уникальный URL |
| `category` | ForeignKey→PortfolioCategory | Категория проекта (CASCADE) |
| `client` | ForeignKey→Client | Клиент-заказчик (SET_NULL, необязательно) |
| `image` | ImageField | Главное изображение работы |
| `short_description` | TextField(300) | Краткая аннотация |
| `content` | CKEditor5Field | Полное описание кейса с форматированием |
| `technologies` | CharField(300) | Список технологий через запятую |
| `project_date` | DateField | Дата реализации проекта |
| `project_url` | URLField | Ссылка на живой сайт проекта |
| `github_url` | URLField | Ссылка на исходный код (GitHub) |
| `status` | CharField | Статус (`draft` — Черновик, `published` — Опубликовано, `archived` — В архиве) |
| `views` | PositiveIntegerField | Счётчик просмотров работы |

**Особенности:**
- **Автоматическая генерация новостей**: При сохранении работы со статусом `published` система автоматически генерирует новостную запись о новом проекте в категории "Портфолио" с подробным описанием и ссылкой на проект.

---

### `Order` — Заказ в CRM
Внутренняя CRM-система для работы с текущими заказами клиентов.

| Поле | Тип | Описание |
|------|-----|----------|
| `client` | ForeignKey→Client | Клиент, разместивший заказ (CASCADE) |
| `title` | CharField(200) | Название проекта |
| `description` | TextField | Техническое задание / Описание заказа |
| `budget` | DecimalField | Бюджет проекта |
| `deadline` | DateField | Срок завершения |
| `status` | CharField | Статус заказа (`new` — Новый, `in_progress` — В работе, `completed` — Завершен, `cancelled` — Отменен) |
| `priority` | CharField | Приоритет (`low`, `medium`, `high`, `urgent`) |
| `requirements_file` | FileField | Загруженный файл требований (ТЗ) |

**Свойства:**
- `is_overdue`: Проверяет, просрочен ли дедлайн заказа.
- `get_progress_percentage`: Возвращает процент выполнения в зависимости от текущего статуса заказа (например, `in_progress` — 50%).

---

### `OrderMessage` — Сообщение заказа (Чат)
Встроенная система переписки по каждому конкретному заказу между клиентом и администратором.

| Поле | Тип | Описание |
|------|-----|----------|
| `order` | ForeignKey→Order | Заказ, к которому привязан чат (CASCADE) |
| `user` | ForeignKey→User | Автор сообщения |
| `message` | TextField | Текст сообщения |
| `file` | FileField | Вложенный файл / документ |
| `is_admin_message` | BooleanField | Флаг сообщения от администрации (выставляется автоматически, если `user.is_staff`) |

---

### `PortfolioReview` — Отзыв о работе
Отзыв о качестве работы, привязанный к конкретному кейсу портфолио.

| Поле | Тип | Описание |
|------|-----|----------|
| `client` | ForeignKey→Client | Клиент (CASCADE) |
| `portfolio_item` | ForeignKey→PortfolioItem | Оцениваемая работа (CASCADE) |
| `rating` | IntegerField | Оценка от 1 до 5 звезд (`RATING_CHOICES`) |
| `title` | CharField(200) | Заголовок отзыва |
| `content` | TextField | Подробный текст отзыва |
| `is_approved` | BooleanField | Статус одобрения модератором (публикуется только после проверки) |

## 🌐 Представления (`views.py`)

| Функция/Класс | URL | Описание |
|---------------|-----|----------|
| `portfolio_list` | `/portfolio/` | Галерея выполненных работ с пагинацией (по 9 на странице) |
| `portfolio_detail` | `/portfolio/<slug>/` | Детальный просмотр кейса с блоком похожих проектов и счетчиком просмотров |
| `portfolio_category` | `/portfolio/category/<slug>/` | Фильтрация работ по выбранной категории |
| `client_profile` | `/portfolio/client/` | Личный кабинет клиента с выводом текущих проектов |
| `order_create` | `/portfolio/order/create/` | Форма создания нового заказа (требуется авторизация клиента) |
| `order_detail` | `/portfolio/order/<pk>/` | Детальная страница заказа с интерактивным чатом (`OrderMessage`) и обменом файлами |

## ⚙️ Администрирование (`admin.py`)

В Django Admin интегрированы расширенные инструменты:
- **Фильтрация и поиск** по клиентам, статусам проектов и заказам.
- **Отображение звездного рейтинга** в отзывах (`PortfolioReview`) с помощью встроенной генерации HTML.
- **Управление приоритетами** и перепиской по заказам непосредственно из админки.

---

## 💡 Уникальные фичи
1. **Автогенерация новостей**: Разгружает контент-менеджера, автоматически публикуя красивую новостную статью со ссылкой на проект при его публикации в портфолио.
2. **CRM чат в заказах**: Дает возможность напрямую координировать задачи с клиентом, обмениваясь технической документацией.
3. **Безопасная загрузка файлов**: Все файлы клиентов сохраняются по транслитерированным путям с временными метками для предотвращения пересечения имен.
