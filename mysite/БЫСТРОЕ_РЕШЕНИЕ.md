# БЫСТРОЕ РЕШЕНИЕ: Ссылки не работают после закрытия сайта

## Проблема
После снятия галочки "Сайт закрыт" в админ-панели, ссылки на сайте не работают.

## Решение (выберите один способ)

### Способ 1: Через админ-панель (рекомендуется)
1. Откройте админ-панель: http://127.0.0.1:6678/admin/
2. Перейдите в **"Настройки сайта"**
3. **Снимите галочку "Сайт закрыт"**
4. Нажмите **"Сохранить"**
5. Кэш очистится автоматически ✓

### Способ 2: Через команду терминала (быстрее)
```bash
# Откройте терминал в папке проекта и выполните:
python manage.py toggle_site_status --open
```

### Способ 3: Если ничего не помогло
```bash
# 1. Очистите кэш вручную
python manage.py shell
>>> from django.core.cache import cache
>>> cache.clear()
>>> exit()

# 2. Перезапустите сервер
# Нажмите Ctrl+C для остановки
# Затем запустите снова:
python manage.py runserver
```

## Проверка
1. Откройте сайт в режиме инкогнито
2. Все ссылки должны работать
3. Если нет - очистите кэш браузера (Ctrl+Shift+Del)

## Дополнительные команды

```bash
# Показать текущий статус сайта
python manage.py toggle_site_status --status

# Закрыть сайт
python manage.py toggle_site_status --close

# Закрыть с сообщением
python manage.py toggle_site_status --close --message "Сайт на обслуживании"
```

## Важно!
- Персонал (is_staff=True) всегда имеет доступ к сайту
- Кэш очищается автоматически при изменении настроек
- Подробная документация: см. файл `SITE_CLOSURE_FIX.md`
