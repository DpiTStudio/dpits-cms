# DPITS-CMS — Многостраничный сайт на Django

**DPITS-CMS** — это современная и гибкая CMS система, построенная на Django, предназначенная для управления контентом, сервисами, новостями, портфолио и взаимодействием с клиентами. Проект включает в себя мощные инструменты администрирования (Jazzmin), интеграцию с визуальным редактором (CKEditor 5), систему тикетов, базу знаний и модуль отзывов.

## 1. Общая структура проекта

### Корневые файлы
- **`manage.py`**: Стандартная утилита командной строки Django для управления проектом (запуск сервера, миграции, создание суперпользователя).
- **`requirements.txt`**: Список всех Python-зависимостей проекта.

### Конфигурация (`mysite/`)
- **`settings.py`**: Главный файл настроек.
  - **Безопасность**: Настройка `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS` через `.env`.
  - **Приложения**: Подключение всех модулей (`apps`), включая `jazzmin`, `ckeditor`, `captcha`.
  - **UI Админки**: Детальная настройка темы и меню Jazzmin.
  - **Логирование**: Конфигурация ротации логов в папку `logs/`.
- **`urls.py`**: Главный маршрутизатор URL, подключающий `urls.py` каждого приложения.

## 2. Подробное описание приложений и файлов

### Приложение `main` (Ядро сайта)
Отвечает за общую логику, главную страницу, SEO и статические страницы.

**Файлы:**
- **`models.py`**:
  - `SiteSettings`: Глобальные настройки сайта (логотип, контакты, соцсети). Singleton-модель.
  - `Page`: Динамические страницы с полноценным SEO-модулем.
  - `ManagedFile`: Управление физическими файлами на сервере через админку (с функциями бэкапа и очистки).
- **`views.py`**:
  - `IndexView`: Главная страница (кэшируется).
  - `LogStatsView`: Панель статистики логов для администраторов.
  - `PageDetailView`: Отображение динамических страниц.
- **`custom_context_processors.py`**: Глобальные переменные шаблонов (меню, настройки сайта).
- **`log_utils.py`**: Утилиты для парсинга и анализа лог-файлов.

### Приложение `news` (Новости)
Система управления новостным контентом.

**Файлы:**
- **`models.py`**:
  - `NewsCategory`: Категории новостей.
  - `News`: Сама новость. Содержит счетчик просмотров и метод `increment_views` для атомарного обновления.
- **`views.py`**:
  - `news_list`: Список новостей с пагинацией.
  - `news_detail`: Детальный просмотр статьи.

### Приложение `services` (Услуги)
Каталог предоставляемых услуг с гибкой системой ценообразования.

**Файлы:**
- **`models.py`**:
  - `ServiceCategory`: Категории услуг с поддержкой иерархии и `HeroMixin` для отображения баннеров.
  - `Service`: Модель услуги. Поддерживает различные типы цен: фиксированная, "от", "до", диапазон. Имеет поля для SEO и мультивалютность (RUB, USD, EUR, KZT).
- **`views.py`**:
  - `service_list`: Витрина всех услуг с фильтрацией и поиском.
  - `service_detail`: Страница конкретной услуги. Показывает похожие услуги из той же категории.
  - `service_category`: Фильтрация услуг по категории.

### Приложение `portfolio` (Портфолио и Заказы)
Демонстрация работ и взаимодействие с клиентами через систему заказов.

**Файлы:**
- **`models.py`**:
  - `PortfolioItem`: Проект в портфолио.
  - `Order`: Заказ клиента. Содержит статус, бюджет и сроки.
  - `OrderMessage`: Чат внутри заказа для общения заказчика и исполнителя.
- **`views.py`**:
  - `PortfolioListView`: Галерея работ.
  - `order_detail`: Интерфейс работы с заказом (чат, файлы).

### Приложение `knowledge_base` (База Знаний)
Раздел справки и документации для пользователей.

**Файлы:**
- **`models.py`**:
  - `Category`: Разделы базы знаний с иконками FontAwesome.
  - `Article`: Статьи с поддержкой CKEditor 5. Включает счетчики полезности ("Полезно"/"Не полезно") и просмотров.
- **`views.py`**:
  - `CategoryListView`: Главная страница базы знаний со списком категорий.
  - `ArticleListView`: Список статей в категории.
  - `ArticleDetailView`: Чтение статьи.
  - `SearchResultsView`: Поиск по заголовкам и содержимому статей.

### Приложение `reviews` (Отзывы)
Система сбора обратной связи с премодерацией.

**Файлы:**
- **`models.py`**:
  - `Review`: Отзыв пользователя. Имеет статусы (`pending`, `approved`, `rejected`). Публикуются только одобренные.
- **`views.py`**:
  - `add_review`: Форма добавления отзыва.
  - `review_list`: Список опубликованных отзывов.

### Приложение `accounts` (Пользователи и Тикеты)
Управление профилями и техническая поддержка.

**Файлы:**
- **`models.py`**:
  - `UserProfile`: Расширение стандартной модели `User`. Хранит аватар, телефон и биографию.
  - `Ticket`: Тикет в службу поддержки. Статусы: "Открыт", "В обработке", "Закрыт".
  - `TicketResponse`: Ответы в рамках тикета. Поддерживает вложения (через CKEditor) и флаг `is_admin_response`.
- **`views.py`**:
  - `profile_view`: Личный кабинет пользователя.
  - `ticket_list`, `ticket_detail`: Интерфейс тикет-системы.

### Приложение `feedback` (Обратная связь)
Простая форма контактов для незарегистрированных пользователей или общих вопросов.

**Файлы:**
- **`models.py`**:
  - `FeedbackMessage`: Сообщение с контактной формы. Имеет статус обработки (Новое, Прочитано, Отвечено).
- **`forms.py`**:
  - `FeedbackForm`: Форма с защитой капчей (`django-simple-captcha`).

## 3. Ключевые возможности и улучшения

### 🎨 Дизайн и UI
- **Анимации**: Использование `animations.css` для плавного появления элементов (`fadeIn`, `slideUp`).
- **Jazzmin**: Полностью кастомизированная админ-панель с темной темой, уникальными иконками для каждой модели и удобным меню.

### 🚀 Производительность
- **Кэширование**: Использование Django cache framework для меню, настроек сайта и списков статей.
- **Оптимизация БД**: Повсеместное использование `select_related` и `prefetch_related` для предотвращения N+1 запросов.

### 🛡 Безопасность
- **Капча**: Защита форм обратной связи и регистрации.
- **Валидация**: Строгая проверка типов файлов при загрузке (аватары, документы).

### 📝 Логирование
- Настроен сбор логов в `logs/debug.log` и `logs/error.log`.
- Реализована ротация логов (ограничение по размеру и количеству файлов).
- В админке доступен просмотр статистики ошибок через `LogStatsView`.

## 4. Инструкция по развертыванию

1. **Клонирование и установка зависимостей**:
   ```bash
   git clone <repo_url>
   pip install -r requirements.txt
   ```

2. **Настройка окружения**:
   Создайте файл `.env` в корне проекта:
   ```env
   SECRET_KEY=ващ_секретный_ключ
   DEBUG=True  # Или False для продакшена
   ```

3. **База данных и статика**:
   ```bash
   python manage.py migrate
   python manage.py collectstatic
   ```

4. **Запуск сервера**:
   ```bash
   python manage.py runserver
   ```

5. **Доступ к админке**:
   Перейдите по адресу `/admin` и используйте учетные данные суперпользователя.
