# DPITS-CMS — Многостраничный сайт на Django

**DPITS-CMS** — современная и гибкая CMS-система на базе Django 5.2, предназначенная для управления контентом, услугами, новостями, портфолио и взаимодействием с клиентами. Проект включает мощные инструменты администрирования (Jazzmin), интеграцию с визуальным редактором (CKEditor 5), систему тикетов поддержки, базу знаний, RSS-ленты, XML-карту сайта и модуль отзывов.

## 1. Общая структура проекта

```
mysite/
├── manage.py               # Утилита командной строки Django
├── requirements.txt        # Python-зависимости проекта
├── .env                    # Переменные окружения (SECRET_KEY, DEBUG и т.д.)
├── .htaccess               # Конфигурация Apache (для продакшена)
├── db.sqlite3              # База данных SQLite (для разработки)
├── run_dev.bat             # Скрипт запуска для Windows
├── runserver_https.bat     # Скрипт запуска HTTPS для Windows
├── runserver_https.sh      # Скрипт запуска HTTPS для Linux/macOS
│
├── mysite/                 # Конфигурация проекта Django
├── main/                   # Главное приложение (ядро сайта)
├── news/                   # Модуль новостей
├── services/               # Модуль услуг
├── portfolio/              # Модуль портфолио и заказов
├── reviews/                # Модуль отзывов
├── accounts/               # Модуль пользователей и тикетов
├── feedback/               # Модуль обратной связи
├── knowledge_base/         # Модуль базы знаний
│
├── templates/              # Глобальные HTML-шаблоны
├── static/                 # Исходные статические файлы (CSS, JS, изображения)
├── staticfiles/            # Собранная статика (после collectstatic)
├── media/                  # Загруженные пользователями файлы
└── logs/                   # Лог-файлы приложения
```

## 2. Конфигурация проекта (`mysite/`)

Папка `mysite/` содержит основные файлы конфигурации Django-проекта.

| Файл | Описание |
|------|----------|
| `settings.py` | Главный файл настроек — база данных, установленные приложения, MEDIA/STATIC, кэш, логирование, Jazzmin |

## 3. Приложение `main` — Ядро сайта

Центральное приложение, управляющее главной страницей, глобальными настройками, статическими страницами, поиском и логированием.

📁 Подробная документация: [main/README.md](main/README.md)

### Ключевые модели (`main/models.py`)

| Модель | Описание |
|--------|----------|
| `SingletonModel` | Абстрактный класс — гарантирует единственный экземпляр (паттерн Singleton) |
| `HeroMixin` | Абстрактный миксин — добавляет Hero-секцию (баннер) к любой модели |
| `AppHeroSettings` | Настройки Hero-баннеров для разделов сайта (новости, портфолио, услуги и т.д.) |
| `SiteSettings` | Глобальные настройки сайта: логотип, контакты, SEO, соцсети, статус сайта |
| `Page` | Динамические CMS-страницы с поддержкой SEO и управлением видимостью |
| `ManagedFile` | Управление файлами на диске через админку с резервными копиями |

### Представления (`main/views.py`)

| Класс/Функция | URL | Описание |
|---------------|-----|----------|
| `IndexView` | `/` | Главная страница. Кэширование 15 мин. Отображает последние новости и портфолио |
| `PageDetailView` | `/page/<slug>/` | Детальная страница CMS-контента. Кэширование 10 мин |
| `ContactView` | `/contacts/` | Страница контактов |
| `AboutView` | `/about/` | Страница «О нас» |
| `SearchView` | `/search/` | Полнотекстовый поиск по новостям, портфолио и страницам |
| `SearchApiView` | `/api/search/` | API живого поиска, возвращает JSON |
| `ProfileView` | `/profile/` | Страница профиля пользователя (требует авторизации) |
| `LogStatsView` | `/log-stats/` | Статистика лог-файлов (только для персонала) |
| `ErrorLogView` | `/error-log/` | Просмотр error.log (только для суперпользователей) |
| `custom_404_view` | — | Кастомная страница ошибки 404 |
| `custom_500_view` | — | Кастомная страница ошибки 500 |

### Дополнительные файлы

| Файл | Описание |
|------|----------|
| `context_processors.py` | Глобальные переменные шаблонов (меню, настройки сайта, Hero-контекст) |
| `breadcrumbs.py` | Утилита построения хлебных крошек |
| `log_utils.py` | Парсинг и анализ лог-файлов (размер, категории, последние строки) |
| `signals.py` | Django-сигналы для автоматического обновления кэша |
| `admin.py` | Конфигурация моделей в панели администратора |
| `admin_files.py` | Расширенный файловый менеджер в админке |
| `admin_utils.py` | Вспомогательные функции для панели администратора |
| `apps.py` | Конфигурация приложения (подключение сигналов) |
| `templatetags/` | Кастомные теги шаблонов |
| `management/` | Django management commands |

### Модели (`news/models.py`)

| Модель | Описание |
|--------|----------|
| `NewsTag` | Тег (метка). Поля: `name`, `slug`. Автогенерация slug |

| Файл | Описание |

## ✨ Ключевые технические особенности

### 🎨 Дизайн и UI
- **Premium Dark** тема с glassmorphism-эффектами
- **Jazzmin** — кастомизированная тёмная тема для Django Admin
- **Анимации** — `animations.css` с эффектами `fadeIn`, `slideUp` для всех элементов
- **Responsive** — адаптивный дизайн для мобильных и desktop

### 🚀 Производительность
- **Кэширование** — Django cache framework для меню, настроек сайта, категорий (5–15 мин)
- **N+1 оптимизация** — повсеместное использование `select_related` и `prefetch_related`
- **Атомарные обновления** — счётчики просмотров через `F()` без race condition

### 🛡 Безопасность
- **Капча** (`django-simple-captcha`) — защита форм регистрации и обратной связи
- **Валидация файлов** — строгая проверка расширений при загрузке (jpg/jpeg/png/gif)
- **Переменные окружения** — `SECRET_KEY`, `DEBUG` и пароли вынесены в `.env`

### 📝 Логирование
- Сбор логов в `logs/debug.log` и `logs/error.log`
- Ротация логов (ограничение по размеру и количеству файлов)
- Просмотр статистики через `LogStatsView` в веб-интерфейсе

### 🔍 SEO
- XML-карта сайта (`/sitemap.xml`)
- Файл `robots.txt`
- RSS-ленты для новостей (`/news/feed/`)
- SEO-поля (title, description, keywords) у каждой модели
- Автогенерация slug из названия с проверкой уникальности
