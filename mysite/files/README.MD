# Приложение Files - Управление файлами

## Описание

Приложение `files` предназначено для управления файлами в системе Django. Оно предоставляет функциональность для загрузки, хранения, организации и управления файлами с поддержкой категорий, версий и метаданных.

## Структура приложения

### Файлы и их назначение

#### `__init__.py`
**Назначение:** Инициализационный файл приложения, делает директорию `files` Python-пакетом.

**Что делает:**
- Превращает директорию в Python-пакет
- Позволяет импортировать модули приложения через `from files import ...`

---

#### `apps.py`
**Назначение:** Конфигурация приложения для Django.

**Что делает:**
- Определяет класс `FilesConfig`, который настраивает приложение
- Указывает название приложения (`name = "files"`)
- Задает человекочитаемое название для админ-панели (`verbose_name = "Управление файлами"`)
- Настраивает тип поля первичного ключа по умолчанию

**Основные функции:**
- `FilesConfig`: Класс конфигурации приложения, регистрируется в `INSTALLED_APPS` в `settings.py`

---

#### `models.py`
**Назначение:** Определяет модели базы данных для работы с файлами.

**Что делает:**
Содержит три основные модели:

1. **FileCategory** - Модель категории файлов
   - Хранит информацию о категориях файлов (название, описание, иконка, цвет)
   - Позволяет группировать файлы по категориям
   - Поддерживает порядок отображения и активность категорий

2. **File** - Модель файла
   - Хранит информацию о загруженных файлах
   - Содержит метаданные: размер, MIME тип, MD5 хеш
   - Поддерживает теги, описание, публичный/приватный доступ
   - Автоматически вычисляет размер, MIME тип и хеш при сохранении
   - Ведет счетчик скачиваний
   - Связана с пользователем, загрузившим файл

3. **FileVersion** - Модель версии файла
   - Хранит историю версий файлов (резервные копии)
   - Позволяет отслеживать изменения файлов
   - Связана с основным файлом и пользователем, создавшим версию

**Основные функции:**
- `get_upload_path()`: Определяет путь для сохранения файла на основе категории и даты
- `File.save()`: Автоматически вычисляет метаданные файла при сохранении
- `File._calculate_hash()`: Вычисляет MD5 хеш файла для проверки целостности
- `File.get_absolute_url()`: Возвращает URL для просмотра файла
- `File.get_download_url()`: Возвращает URL для скачивания файла
- `File.increment_download_count()`: Увеличивает счетчик скачиваний
- `File.human_readable_size`: Свойство для отображения размера в удобном формате
- `File.file_extension`: Свойство для получения расширения файла

---

#### `forms.py`
**Назначение:** Определяет формы для работы с файлами через веб-интерфейс.

**Что делает:**
Содержит четыре формы:

1. **FileUploadForm** - Форма для загрузки нового файла
   - Поля: название, файл, категория, описание, теги, публичный доступ
   - Валидация размера файла (максимум 100 МБ)
   - Автоматическая очистка и валидация тегов
   - Сохранение оригинального имени файла

2. **FileEditForm** - Форма для редактирования существующего файла
   - Поля: название, категория, описание, теги, публичный доступ, активность
   - Не позволяет изменить сам файл, только метаданные
   - Валидация и очистка тегов

3. **FileCategoryForm** - Форма для создания и редактирования категорий
   - Поля: название, описание, иконка, цвет, порядок, активность
   - Валидация уникальности названия
   - Валидация формата HEX цвета

4. **FileSearchForm** - Форма для поиска файлов
   - Поля: поисковый запрос, категория, только публичные, только активные
   - Используется для фильтрации списка файлов

**Основные функции:**
- `FileUploadForm.clean_file()`: Валидация размера и типа файла
- `FileUploadForm.clean_tags()`: Очистка и валидация тегов
- `FileCategoryForm.clean_name()`: Проверка уникальности названия категории
- `FileCategoryForm.clean_color()`: Валидация формата HEX цвета

---

#### `views.py`
**Назначение:** Обрабатывает HTTP-запросы для работы с файлами.

**Что делает:**
Содержит представления (views) для различных операций:

1. **FileListView** - Список всех файлов
   - Отображает список файлов с пагинацией (20 на страницу)
   - Поддерживает поиск и фильтрацию через форму
   - Показывает категории для фильтрации

2. **FileDetailView** - Детальная информация о файле
   - Показывает полную информацию о файле
   - Отображает версии файла
   - Оптимизирует запросы к базе данных

3. **FileDownloadView** - Скачивание файла
   - Отдает файл пользователю для скачивания
   - Проверяет права доступа (публичный/приватный)
   - Увеличивает счетчик скачиваний
   - Использует FileResponse для отдачи файла

4. **FileUploadView** - Загрузка нового файла
   - Требует авторизации пользователя (LoginRequiredMixin)
   - Обрабатывает форму загрузки
   - Связывает файл с текущим пользователем
   - Сохраняет оригинальное имя файла

5. **FileUpdateView** - Редактирование файла
   - Требует авторизации
   - Позволяет редактировать только свои файлы (или администратору все)
   - Обновляет метаданные файла

6. **FileDeleteView** - Удаление файла
   - Требует авторизации
   - Позволяет удалять только свои файлы (или администратору все)
   - Удаляет файл с диска при удалении записи

7. **FileCategoryListView** - Список категорий
   - Показывает все активные категории

8. **FileCategoryDetailView** - Детальная информация о категории
   - Показывает все файлы в категории

**Основные функции:**
- `FileListView.get_queryset()`: Фильтрация и поиск файлов
- `FileListView.get_context_data()`: Добавление формы поиска в контекст
- `FileDownloadView.get()`: Обработка запроса на скачивание
- `FileUploadView.form_valid()`: Обработка успешной загрузки
- `FileUpdateView.get_queryset()`: Фильтрация по правам доступа

---

#### `urls.py`
**Назначение:** Определяет URL-маршруты для приложения.

**Что делает:**
Создает пространство имен `files` и определяет следующие маршруты:

- `/` - Список файлов (`file_list`)
- `/<int:pk>/` - Детальная информация о файле (`file_detail`)
- `/<int:pk>/download/` - Скачивание файла (`file_download`)
- `/upload/` - Загрузка нового файла (`file_upload`)
- `/<int:pk>/edit/` - Редактирование файла (`file_edit`)
- `/<int:pk>/delete/` - Удаление файла (`file_delete`)
- `/categories/` - Список категорий (`category_list`)
- `/categories/<int:pk>/` - Детальная информация о категории (`category_detail`)

**Использование:**
Все URL доступны через пространство имен `files`, например:
- `{% url 'files:file_list' %}`
- `{% url 'files:file_detail' pk=1 %}`

---

#### `admin.py`
**Назначение:** Настраивает интерфейс администратора Django для управления файлами.

**Что делает:**
Содержит три класса админ-панели:

1. **FileCategoryAdmin** - Админ-панель для категорий
   - Отображает: название, иконку, цвет, порядок, количество файлов, активность
   - Фильтры: активность, дата создания
   - Поиск: по названию и описанию
   - Редактирование порядка и активности прямо в списке

2. **FileAdmin** - Админ-панель для файлов
   - Отображает: название, категорию, размер, MIME тип, количество скачиваний, публичность, активность, загрузившего, дату
   - Фильтры: категория, публичность, активность, дата, загрузивший
   - Поиск: по названию, оригинальному имени, описанию, тегам
   - Редактирование публичности и активности прямо в списке
   - Предпросмотр изображений
   - Встроенная админ-панель для версий файлов

3. **FileVersionAdmin** - Админ-панель для версий файлов
   - Отображает: файл, номер версии, создавшего, дату, размер
   - Фильтры: дата создания, файл
   - Поиск: по названию файла и комментарию
   - Автоматическое заполнение создавшего при создании

**Основные функции:**
- `FileCategoryAdmin.icon_display()`: Отображение иконки категории
- `FileCategoryAdmin.color_display()`: Отображение цвета категории
- `FileCategoryAdmin.file_count()`: Подсчет файлов в категории
- `FileAdmin.file_size_display()`: Отображение размера в удобном формате
- `FileAdmin.file_preview()`: Предпросмотр изображений
- `FileVersionAdmin.file_size_display()`: Отображение размера версии
- `FileVersionAdmin.save_model()`: Автоматическое заполнение создавшего

---

#### `tests.py`
**Назначение:** Содержит unit-тесты для проверки функциональности приложения.

**Что делает:**
Содержит три класса тестов:

1. **FileCategoryModelTest** - Тесты модели категорий
   - Тест создания категории
   - Тест строкового представления

2. **FileModelTest** - Тесты модели файлов
   - Тест создания файла
   - Тест форматирования размера

3. **FileViewsTest** - Тесты представлений
   - Тест списка файлов
   - Тест загрузки файла (требует авторизации)
   - Тест загрузки для авторизованного пользователя

**Использование:**
Запуск тестов: `python manage.py test files`

---

#### `migrations/__init__.py`
**Назначение:** Инициализационный файл для миграций базы данных.

**Что делает:**
- Делает директорию `migrations` Python-пакетом
- Миграции используются для управления изменениями в структуре базы данных
- При создании моделей Django автоматически создает миграции в этой директории

**Использование:**
- Создание миграций: `python manage.py makemigrations files`
- Применение миграций: `python manage.py migrate files`

## Установка и настройка

### 1. Добавление приложения в проект

Приложение уже добавлено в `settings.py`:
```python
INSTALLED_APPS = [
    ...
    "files.apps.FilesConfig",  # Управление файлами
]
```

И в `urls.py`:
```python
urlpatterns = [
    ...
    path("files/", include("files.urls")),  # Маршруты для управления файлами
]
```

### 2. Применение миграций

После добавления приложения необходимо применить миграции:
```bash
python manage.py makemigrations files
python manage.py migrate files
```

### 3. Создание суперпользователя (если еще не создан)

Для доступа к админ-панели:
```bash
python manage.py createsuperuser
```

### 4. Использование

- **Веб-интерфейс:** Доступен по адресу `/files/`
- **Админ-панель:** Доступна по адресу `/admin/files/`
- **API через views:** Используйте представления для программного доступа

## Основные возможности

1. **Загрузка файлов**
   - Поддержка файлов до 100 МБ
   - Автоматическое определение MIME типа
   - Вычисление MD5 хеша для проверки целостности
   - Организация файлов по категориям и датам

2. **Организация файлов**
   - Категории с иконками и цветами
   - Теги для поиска
   - Описания для каждого файла

3. **Управление доступом**
   - Публичные и приватные файлы
   - Привязка к пользователю
   - Контроль активности файлов

4. **Версионирование**
   - История версий файлов
   - Резервные копии
   - Комментарии к версиям

5. **Поиск и фильтрация**
   - Поиск по названию, описанию, тегам
   - Фильтрация по категориям
   - Фильтрация по публичности и активности

6. **Статистика**
   - Счетчик скачиваний
   - Размер файлов
   - Дата загрузки и обновления

## Зависимости

Приложение использует стандартные компоненты Django:
- `django.contrib.auth` - для работы с пользователями
- `django.core.files` - для работы с файлами
- `django.core.validators` - для валидации
- `django.utils.translation` - для интернационализации

---

## Безопасность

1. **Проверка прав доступа:**
   - Загрузка файлов требует авторизации
   - Редактирование/удаление только своих файлов (или администратору все)
   - Публичные файлы доступны всем, приватные - только авторизованным

2. **Валидация файлов:**
   - Ограничение размера (100 МБ)
   - Проверка типов файлов
   - MD5 хеш для проверки целостности

3. **Защита от перезаписи:**
   - Уникальные пути для файлов
   - Версионирование для отслеживания изменений

## Расширение функциональности

Для расширения приложения можно:

1. **Добавить новые типы файлов:**
   - Расширить валидацию в `forms.py`
   - Добавить обработку специфичных типов в `models.py`

2. **Добавить новые представления:**
   - Создать новые классы в `views.py`
   - Добавить маршруты в `urls.py`

3. **Расширить админ-панель:**
   - Добавить кастомные действия в `admin.py`
   - Создать кастомные шаблоны для админки

4. **Добавить API:**
   - Использовать Django REST Framework
   - Создать сериализаторы для моделей

## Поддержка

При возникновении проблем:
1. Проверьте логи Django
2. Убедитесь, что миграции применены
3. Проверьте права доступа к директории `media/files/`
4. Проверьте настройки `MEDIA_ROOT` и `MEDIA_URL` в `settings.py`
