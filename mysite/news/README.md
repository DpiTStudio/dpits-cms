# 📰 Приложение News (Новости)

Модуль для управления новостным контентом на сайте. Позволяет создавать, редактировать и публиковать новости с распределением по категориям.

## 📋 Основные возможности

*   **Категории новостей**: Группировка новостей по темам (например, "Обновления", "События").
*   **SEO-оптимизация**: Индивидуальные настройки Meta Title, Keywords, Description для каждой новости и категории.
*   **Hero-секции**: Настройка заголовков и фоновых изображений для каждой страницы.
*   **WYSIWYG редактор**: Использование CKEditor 5 для форматирования текста.
*   **Счетчик просмотров**: Отслеживание популярности публикаций.

## 🗄 Модели данных

### `NewsCategory` (Категория новостей)
*   Группирует новости.
*   Поддерживает иерархию отображения (порядок `order`).
*   Имеет собственные SEO-настройки.

### `News` (Новость)
*   Основная сущность контента.
*   Поля: Заголовок, Слаг (URL), Категория, Изображение, Краткое описание, Полный контент.
*   Системные поля: Просмотры, Дата создания/обновления.
*   Автоматическая генерация слагов.

## 🔗 URL Structure
*   Список новостей: `/news/`
*   Категория: `/news/category/<slug>/`
*   Детальная страница: `/news/<slug>/`
