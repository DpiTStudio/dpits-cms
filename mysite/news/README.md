# Приложение News (Новости)

Приложение `news` предназначено для публикации новостей, статей и анонсов на сайте. Оно предоставляет мощные инструменты для управления контентом, SEO-оптимизации, отложенной публикации и взаимодействия с пользователями.

---

## 🚀 Новые возможности и улучшения (Май 2026)

В рамках недавних обновлений приложение `news` получило следующие функции и улучшения:

1. **Система древовидных комментариев (Comments & Replies)**:
   - Добавлены древовидные (вложенные) комментарии к каждой новости.
   - Поддерживаются как авторизованные пользователи, так и гости.
   - Для гостей интегрирована защита от спама с использованием капчи (`django-simple-captcha`).
   - Комментарии публикуются и рендерятся в реальном времени через AJAX.
2. **Эмодзи-реакции (Emoji Reactions)**:
   - Внедрен виджет экспресс-реакций (👍, ❤️, 🔥, 😮, 😢) под текстом статей.
   - Накрутки ограничены с помощью фиксации сессий и IP-адресов в БД.
   - Отправка и подсчет реакций работают на базе AJAX.
3. **Аудио-плеер воспроизведения текста (TTS)**:
   - Встроен премиум виджет аудиоверсии статьи.
   - Использует встроенный синтезатор речи браузера (`window.speechSynthesis`), работающий на клиенте без внешних серверов.
   - Предусмотрена возможность паузы, остановки речи и выбора скорости воспроизведения.
4. **Автоматическая WebP оптимизация изображений**:
   - При сохранении новостей или категорий все загружаемые картинки автоматически конвертируются в формат `.webp`.
   - Происходит ресайз изображений (максимально 1200px по ширине/высоте) для минимизации веса картинок и ускорения загрузки страниц.
5. **Корректировка Sitemap**:
   - Обновлен `NewsSitemap` для исключения еще не опубликованных (запланированных на будущее) новостей из файла `sitemap.xml`.
6. **Отложенная публикация (`published_at`)**: Теперь администраторы могут задавать дату публикации в будущем. Новость автоматически появится на сайте только при наступлении этой даты.
7. **Время чтения**: Автоматический подсчет примерного времени чтения новости на основе количества слов (200 слов в минуту), что повышает вовлеченность пользователей.
8. **Продвинутое SEO**: 
   - Внедрена микроразметка **Schema.org (JSON-LD)** формата `NewsArticle`.
   - Внедрены мета-теги **Open Graph** и **Twitter Cards** для красивого превью при публикации ссылки в мессенджерах (Telegram, WhatsApp) и соцсетях (VK).
   - Внедрен атрибут **Canonical URL** для предотвращения дублирования страниц в поисковых системах.
9. **Умные рекомендации**: Блок «Похожие новости» теперь сначала анализирует **теги (`tags`)** текущей новости, и только потом, если нужно, дополняет список новостями из той же категории.
10. **Auto-discovery RSS**: В заголовок сайта (`base.html`) добавлен тег для автоматического обнаружения RSS-ленты браузерами и агрегаторами.
11. **Кнопки шеринга**: В шаблоне новости добавлены кнопки для быстрого репоста в VK, Telegram, WhatsApp и копирования ссылки.

## 📂 Структура приложения и описание файлов

### `models.py` - Модели данных
- **`NewsCategory`**: Категория новостей. Поддерживает SEO-поля, изображения, описание, сортировку и настройки отображения в меню.
- **`NewsTag`**: Теги для группировки новостей и поиска.
- **`News`**: Основная модель новости. 
  - *Особенности*: 
    - Умное наследование изображений от категории (если не задано собственное).
    - Расчет времени чтения (свойство `get_reading_time`).
    - Безопасный инкремент просмотров через `F("views") + 1` (`increment_views()`).
    - Поддержка CKEditor5 для контента.

### `views.py` - Представления
Оптимизированы с помощью `select_related` для снижения нагрузки на БД.
- **`news_list`**: Список всех активных и опубликованных новостей. Поддерживает уровневую сортировку, фильтрацию по категориям и поиск.
- **`news_detail`**: Детальная страница новости. Содержит логику для сбора ленты новостей за текущий день (`daily_news`) и алгоритм умных рекомендаций (`similar_news`).
- **`news_by_category`**: Вывод новостей конкретной категории.
- **`news_search`**: Полнотекстовый поиск по заголовкам, краткому описанию и контенту.
- **`news_by_tag`**: Фильтрация новостей по выбранному тегу.

### `admin.py` - Административная панель
Интерфейс администратора для управления новостями.
- Расширен класс `NewsAdmin` с добавлением фильтрации по `published_at` и `is_active`.
- Имеется встроенный экшен (Action) и кнопка для ручного обнуления счетчика просмотров новостей.

### `urls.py` - Маршрутизация
Содержит пути для всех представлений, включая пути для API (получение картинки категории) и фидов (`feed/`).

### `feeds.py` - RSS ленты
Генерация RSS 2.0 фидов с использованием `django.contrib.syndication`.
- `LatestNewsFeed`: Общая лента последних новостей.
- `NewsByCategoryFeed`: RSS лента для конкретных категорий.
(Все ленты учитывают дату отложенной публикации `published_at`).

### `utils.py` - Утилиты и кэширование
Содержит функции для работы с кэшем Django (например, `get_cached_news_categories`), обеспечивая быструю загрузку сквозных блоков (сайдбара и фильтров).

### `context_processors.py`
Глобальные переменные для шаблонов, если это необходимо (может использоваться для вывода списка категорий во всех шаблонах сайта).

## 🎨 Шаблоны (`templates/news/`)

- **`list.html`**: Современный шаблон списка новостей с группировкой по датам (Timeline), карточками "Главная новость дня" и удобной панелью фильтрации.
- **`detail.html`**: Шаблон отдельной новости. Включает микроразметку Schema.org, кнопки "Поделиться", блок похожих новостей и ленту событий за день.

## 🔧 Зависимости
- `django-ckeditor-5` (Для визуального редактора)
- `Pillow` (Для работы с `ImageField` в моделях)

## 📌 Заметки для разработчиков
- При выборке новостей всегда используйте фильтрацию: `News.objects.filter(is_active=True, published_at__lte=timezone.now())`.
- Подсчет просмотров реализован с использованием `F()` выражений БД для предотвращения Race Condition при высокой нагрузке.
- В шаблонах активно используется `{% cache %}` или утилитные функции с кэшированием для блоков, которые редко меняются.
