# Приложение `reviews` — Отзывы

Система сбора отзывов пользователей с обязательной премодерацией. На сайте публикуются только одобренные администратором отзывы.

---

## 📁 Структура файлов

```
reviews/
├── models.py           # Модель Review
├── views.py            # Представления
├── urls.py             # URL-маршруты
├── forms.py            # Форма добавления отзыва
├── admin.py            # Конфигурация Django Admin
├── apps.py             # Конфигурация приложения
├── migrations/         # Миграции базы данных
└── templates/reviews/  # HTML-шаблоны
```

---

## 📦 Модели (`models.py`)

### `Review` — Отзыв пользователя

**Статусы:**

| Константа | Значение | Описание |
|-----------|---------|----------|
| — | `pending` | Ожидает модерации (default) |
| — | `approved` | Одобрен — виден на сайте |
| — | `rejected` | Отклонён администратором |

| Поле | Тип | Описание |
|------|-----|----------|
| `author` | ForeignKey→User | Автор отзыва (необязательно, null=True) |
| `email` | EmailField(254) | Email автора |
| `full_name` | CharField(100) | ФИО автора |
| `message` | TextField | Текст отзыва |
| `phone` | CharField(20) | Телефон автора |
| `status` | CharField(10) | Статус модерации (default: `pending`) |
| `id_review` | AutoField | Первичный ключ (явный) |
| `created_at` | DateTimeField | Дата создания (auto_now_add) |
| `updated_at` | DateTimeField | Дата обновления (auto_now) |

**Мета-настройки:**
- `verbose_name`: «Отзыв» / «Отзывы»
- `ordering`: `["-created_at"]` (новые сверху)
- `__str__`: `f"{full_name} - {created_at}"`

## 🌐 Представления (`views.py`)

| Функция/Класс | URL | Описание |
|---------------|-----|----------|
| `review_list` | `/reviews/` | Список **одобренных** отзывов (`status="approved"`) |
| `add_review` | `/reviews/add/` | Форма добавления отзыва. После отправки — статус `pending` (ожидает проверки) |

---

## 📝 Формы (`forms.py`)

**`ReviewForm`** — форма добавления отзыва:
- Поля: `full_name`, `email`, `phone`, `message`
- Защита капчей (`django-simple-captcha`)

---

## ⚙️ Администрирование (`admin.py`)

В Django Admin доступно:
- Список всех отзывов с фильтром по статусу
- Действия: **Одобрить** / **Отклонить** выбранные отзывы
- Просмотр и редактирование отдельного отзыва

---

## 🗺 URL-маршруты (`urls.py`)

Пространство имён: `reviews`

| Имя | URL | Описание |
|-----|-----|----------|
| `reviews:list` | `/reviews/` | Список одобренных отзывов |
| `reviews:add` | `/reviews/add/` | Форма добавления отзыва |

---

## 💡 Логика модерации

1. Пользователь заполняет форму → отзыв сохраняется со статусом `pending`
2. Администратор в панели управления просматривает новые отзывы
3. При одобрении (`approved`) отзыв автоматически появляется на странице `/reviews/`
4. При отклонении (`rejected`) отзыв не отображается на сайте
