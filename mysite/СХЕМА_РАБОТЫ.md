## Структура файлов

```
mysite/
├── main/
│   ├── views.py
│   │   └── MaintenanceMixin.dispatch()  ← Проверка site_closed
│   ├── signals.py
│   │   └── clear_site_settings_cache()  ← Очистка кэша
│   ├── models.py
│   │   └── SiteSettings                 ← Модель настроек
│   ├── templates/main/
│   │   └── site_closed.html             ← Страница обслуживания
│   └── management/commands/
│       └── toggle_site_status.py        ← Команда управления
├── SITE_CLOSURE_FIX.md                  ← Подробная документация
└── БЫСТРОЕ_РЕШЕНИЕ.md                   ← Краткая инструкция
```

## Ключевые моменты

1. **Без кэширования статуса**: `MaintenanceMixin` загружает настройки напрямую из БД
2. **Автоматическая очистка**: Сигнал `post_save` очищает весь кэш
3. **Доступ для персонала**: Пользователи с `is_staff=True` всегда имеют доступ
4. **Немедленное применение**: Изменения вступают в силу сразу после сохранения
