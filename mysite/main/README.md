# ⚙️ Приложение Main (Ядро)

Центральное приложение проекта, отвечающее за конфигурацию, статические страницы, настройки сайта и управление файлами.

## 🚀 Основные компоненты

*   **CMS Страницы (`Page`)**:
    *   Создание динамических страниц через админку.
    *   Настройка URL (slug), контента, SEO.
    *   Управление порядком и видимостью в меню.
*   **Настройки сайта (`SiteSettings`)**:
    *   Singleton-модель (одна запись на весь сайт).
    *   Управление заголовком, логотипом, контактами, соцсетями.
    *   Глобальные SEO настройки.
    *   Режим "Сайт закрыт" (Technical maintenance).
*   **Файловый менеджер (`ManagedFile`)**:
    *   Управление физическими файлами на сервере через админку.
    *   Просмотр логов, редактирование конфигов.
    *   Создание бэкапов файлов.
*   **Hero Mixin**:
    *   Абстрактная модель для добавления Hero-секций (баннеров) к любым другим сущностям (Страницы, Категории и т.д.).
    *   `AppHeroSettings`: Настройка Hero-секций для общих списков (Новости, Услуги).

## 🛠 Особенности реализации
*   Реализация паттерна Singleton для настроек.
*   Глубокая интеграция с CKEditor 5.
*   Утилиты для работы с файловой системой.
