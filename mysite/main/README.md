# Приложение `main` — Ядро сайта

Центральное приложение проекта DPITS-CMS. Отвечает за глобальные настройки сайта, главную страницу, CMS-страницы, поиск, логирование и обслуживание Hero-секций.

---

## 📁 Структура файлов

```
main/
├── models.py               # Модели данных
├── views.py                # Представления (контроллеры)
├── urls.py                 # Маршруты URL
├── admin.py                # Конфигурация Django Admin
├── admin_files.py          # Файловый менеджер в Admin

├── apps.py                 # Конфигурация приложения

├── signals.py              # Django-сигналы
├── tests.py                # Тесты
```

## 📦 Модели (`models.py`)

### `SingletonModel` — Базовый класс-одиночка

**Назначение:** Абстрактная базовая модель, гарантирующая существование только **одного** экземпляра в базе данных.

**Как работает:**
- Метод `save()` принудительно устанавливает `pk = 1` при каждом сохранении
- Метод `load()` возвращает единственный экземпляр, создавая его при необходимости

**Используется в:** `SiteSettings`

---

### `HeroMixin` — Миксин Hero-секции

**Назначение:** Абстрактный миксин, добавляющий поля для настройки баннера (hero) к любой модели.

**Поля:**

| Поле | Тип | Описание |
|------|-----|----------|
| `hero_title` | CharField (255) | Заголовок баннера (переопределяет стандартный) |
| `hero_subtitle` | TextField | Подзаголовок баннера |
| `hero_image` | ImageField | Фоновое изображение баннера |
| `hero_is_active` | BooleanField | Показывать ли Hero-секцию на странице |

**Используется в:** `NewsCategory`, `News`, `ServiceCategory`, `Service`, `PortfolioCategory`, `PortfolioItem`, `Page`

---

### `AppHeroSettings` — Настройки Hero для разделов

**Назначение:** Хранит индивидуальные настройки Hero-баннера для конкретных разделов сайта.

**Поддерживаемые разделы:**
- Новости, Портфолио, Услуги, Отзывы, Контакты, О нас, Профиль, Главная

---

### `SiteSettings` — Глобальные настройки сайта

**Назначение:** Singleton-модель для единственной записи глобальных настроек сайта.

**Группы полей:**

#### Брендинг
| Поле | Описание |
|------|----------|
| `logo` | Логотип сайта (рекомендуемый размер: 200×60 px) |
| `company_name` | Название компании |
| `hero_background` | Фоновое изображение главного баннера |
| `logo_text` | Текстовый вариант логотипа |
| `slogan` | Слоган компании |
| `motto` | Девиз (CKEditor) |
| `short_description` | Краткое описание (CKEditor) |
| `content` | Основной контент (CKEditor) |

#### Контакты
| Поле | Описание |
|------|----------|
| `title` | Название сайта |
| `phone1` | Основной телефон |
| `phone2` | Дополнительный телефон |
| `email` | Электронная почта |
| `address` | Физический адрес |
| `domain` | Домен сайта |
| `slogan_domain` | Слоган домена |

#### Социальные сети и мессенджеры
Поддерживаются: Facebook, Instagram, YouTube, Rutube, VK Video, Telegram, ВКонтакте, Одноклассники, Twitter(X), Pinterest, LinkedIn, Threads, WhatsApp, Viber, Skype. Для каждой сети — поле URL и поле иконки.

#### SEO
| Поле | Описание |
|------|----------|
| `seo_title` | SEO-заголовок для тега `<title>` |
| `seo_keywords` | Ключевые слова через запятую |
| `seo_description` | Мета-описание для поисковых систем |

#### Статус сайта
| Поле | Описание |
|------|----------|
| `site_closed` | Флаг закрытия сайта (технические работы) |
| `closure_message` | Сообщение при закрытии |

**Ключевые методы:**
- `get_social_links()` — возвращает список активных ссылок на соцсети/мессенджеры для шаблонов
- `clean()` — валидация (запрет сохранения без closure_message при site_closed=True)

---

### `Page` — CMS-страницы

**Назначение:** Управляемые пользователем страницы сайта с полноценным SEO-модулем.

**Поля:**

| Поле | Описание |
|------|----------|
| `title` | Заголовок страницы |
| `slug` | URL-адрес (уникальный) |
| `content` | Содержимое (CKEditor 5) |
| `show_in_menu` | Показывать в навигационном меню |
| `show_on_site` | Страница видна на сайте |
| `order` | Порядок сортировки (меньше = выше) |
| `seo_title` | SEO-заголовок |
| `seo_keywords` | SEO-ключевые слова |
| `seo_description` | SEO-описание |

**Ключевые методы:**
- `get_absolute_url()` — URL вида `/page/<slug>/`
- `get_previous_page()` / `get_next_page()` — навигация по документу
- `display_title` — свойство: возвращает SEO-заголовок или обычный
- `clean()` — запрет зарезервированных slug (`admin`, `login`, `logout`, `password`)

**Сортировка по умолчанию:** `["order", "title"]`

---

### `ManagedFile` — Управление файлами

**Назначение:** Позволяет управлять физическими файлами на сервере через Django Admin: просматривать, редактировать содержимое, создавать резервные копии.

**Категории файлов:** лог-файлы, конфигурационные, шаблоны, статические, медиа, базы данных, резервные копии, прочие.

**Ключевые поля:**
- `file_path` — абсолютный путь к файлу (уникальный)
- `is_text_file` — является ли файл текстовым (позволяет редактировать)
- `auto_backup` — автоматическое резервное копирование при изменении
- `max_backups` — максимальное количество резервных копий

## 🌐 Представления (`views.py`)

### `MaintenanceMixin`
Миксин для всех представлений. Проверяет флаг `SiteSettings.site_closed`. Если сайт закрыт, обычные пользователи видят страницу `main/site_closed.html`. Персонал (is_staff) сайт видит.

### `BaseView`
Базовый класс-представление. Добавляет в контекст:
- `site_settings` (с кэшированием 5 мин)
- `page_title`, `meta_description`, `meta_keywords`

### `IndexView` — Главная страница
- **Шаблон:** `main/home.html`
- **URL:** `/`
- **Кэширование:** `@cache_page(60 * 15)`, `@vary_on_cookie`
- **Контекст:** `featured_pages` (до 6 страниц, кэш 10 мин), `recent_news_list` (3 новости), `recent_portfolio_list` (3 работы)

### `PageDetailView` — Детальная страница
- **Шаблон:** `main/page_detail.html`
- **URL:** `/page/<slug>/`
- **Кэширование:** `@cache_page(60 * 10)`
- **Особенности:** Только активные страницы (`show_on_site=True`). Навигация предыдущая/следующая страница. SEO из модели.

### `ContactView` — Контакты
- **Шаблон:** `main/contacts.html`
- **URL:** `/contacts/`

### `AboutView` — О нас
- **Шаблон:** `main/about.html`
- **URL:** `/about/`

### `SearchView` — Поиск
- **Шаблон:** `main/search_results.html`
- **URL:** `/search/?q=запрос`
- **Поиск по:** новостям (title, short_description, content), портфолио, страницам

### `SearchApiView` — API живого поиска
- **URL:** `/api/search/?q=запрос`
- **Ответ:** JSON с полями `title`, `url`, `type`, `icon`
- Минимальная длина запроса: 2 символа

### `ProfileView` — Профиль пользователя
- **Шаблон:** `main/profile.html`
- **URL:** `/profile/`
- **Требования:** Пользователь должен быть авторизован

### `LogStatsView` — Статистика логов
- **Шаблон:** `main/log_stats.html`
- **URL:** `/log-stats/`
- **Требования:** `is_authenticated` + `is_staff`
- **Отображает:** информацию о лог-файле, последние 50 строк, статистику по категориям

### `custom_404_view` / `custom_500_view`
Кастомные страницы ошибок с контекстом `site_settings`.

## 🔧 Вспомогательные файлы

### `context_processors.py`
Добавляет в контекст **всех** шаблонов проекта:
- Настройки сайта (`site_settings`)
- Пункты меню (`menu_pages`)
- Контекст Hero-секции для текущей страницы

### `breadcrumbs.py`
Функция `get_breadcrumbs(items)` — формирует структуру хлебных крошек.

**Входной формат:**
```python
get_breadcrumbs([
    ("Новости", reverse("news:list"), "fas fa-newspaper"),
    ("Заголовок статьи", None),
])
```

### `log_utils.py`
Утилиты для работы с лог-файлами:
- `get_log_file_info()` — размер файла, дата изменения, количество строк
- `get_recent_log_lines(n)` — последние N строк лога
- `count_total_lines()` — общее количество строк
- `count_lines_by_category()` — количество строк по уровням: ERROR, WARNING, INFO, DEBUG

### `signals.py`
Django-сигналы для автоматического сброса кэша при изменении `SiteSettings` и `Page`.

### `admin_files.py`
Расширенный файловый менеджер в Django Admin:
- Просмотр и редактирование текстовых файлов
- Создание редервных копий
- Отображение метаданных файла
