# DPITS-CMS - Система управления контентом

## Описание проекта
DPITS-CMS - это система управления контентом на основе Django, предоставляющая функциональность для управления сайтом, страницами, настройками и файлами через административную панель.

## Структура проекта

### Основные файлы:

#### 1. `admin.py` - Административная панель
**Описание**: Содержит конфигурации для админ-панели Django.
**Модели**:
- `SiteSettingsAdmin` - управление настройками сайта (singleton)
- `PageAdmin` - управление страницами сайта
- `ManagedFileAdmin` - управление файлами на диске

**Функциональность**:
- Редактирование настроек сайта
- Управление страницами с SEO-оптимизацией
- Просмотр и редактирование файлов на диске
- Создание резервных копий файлов
- Очистка и удаление файлов

#### 2. `models.py` - Модели базы данных
**Основные модели**:
- `SingletonModel` - абстрактная модель для singleton-объектов
- `SiteSettings` - настройки сайта (контакты, соцсети, SEO, статус)
- `Page` - страницы сайта с поддержкой SEO и навигации
- `ManagedFile` - модель для управления файлами на диске

**Функции моделей**:
- Автоматическое определение MIME-типов
- Чтение содержимого файлов с различными кодировками
- Создание резервных копий
- Проверка существования файлов

#### 3. `views.py` - Контроллеры (представления)
**Основные представления**:
- `MaintenanceMixin` - миксин для проверки статуса обслуживания
- `BaseView` - базовый класс с общими данными
- `IndexView` - главная страница
- `PageDetailView` - детальная страница
- `ContactView`, `AboutView`, `ProfileView` - статические страницы
- Обработчики ошибок 404 и 500

**Особенности**:
- Кэширование страниц
- SEO-оптимизация
- Наследование общих настроек

#### 4. `urls.py` - Маршруты URL
**Маршруты**:
- Главная страница (`/`)
- Страницы (`/page/<slug>/`)
- Контакты, О нас, Профиль
- Обработчики ошибок

#### 5. `signals.py` - Сигналы Django
**Назначение**: Очистка кэша при изменениях в моделях.
**Сигналы**:
- При сохранении/удалении SiteSettings
- При сохранении/удалении Page
- При сохранении/удалении ManagedFile

#### 6. `context_processors.py` - Контекстные процессоры
**Процессоры**:
- `site_settings` - настройки сайта для всех шаблонов
- `menu_items` - меню навигации
- `sidebar_data` - данные для сайдбара (новости, портфолио, отзывы)
- `seo_context` - базовые SEO-данные

#### 7. `apps.py` - Конфигурация приложения
**Настройки**:
- Имя приложения: `main`
- Человекочитаемое имя: "Основные настройки"
- Автоинкрементные первичные ключи

#### 8. Шаблоны (templates/main/)
**Основные шаблоны**:
- `index.html` - главная страница
- `page_detail.html` - детальная страница
- `contacts.html`, `about.html`, `profile.html` - статические страницы
- `404.html`, `500.html` - страницы ошибок
- `site_closed.html` - страница обслуживания

**Шаблоны админки**:
- `managedfile_change_form.html` - форма редактирования файлов
- `managedfile_change_list.html` - список файлов
- `confirm_clear_files.html` - подтверждение очистки файлов

## Функциональные возможности

### 1. Управление сайтом
- Единые настройки сайта (singleton)
- Контактная информация
- Социальные сети
- SEO-оптимизация
- Статус сайта (открыт/закрыт)

### 2. Управление страницами
- Создание/редактирование страниц
- Управление видимостью в меню и на сайте
- Порядок отображения
- SEO для каждой страницы
- Автоматическая навигация (предыдущая/следующая)

### 3. Управление файлами
- Просмотр файлов на диске
- Редактирование текстовых файлов
- Автоматическое создание резервных копий
- Очистка и удаление файлов
- Сканирование директорий
- Информация о файлах (размер, права доступа, MIME-тип)

### 4. Производительность
- Кэширование настроек сайта
- Кэширование меню и сайдбара
- Кэширование страниц
- Оптимизированные запросы к БД

## Установка и настройка

### Требования
- Python 3.8+
- Django 4.0+
- django-ckeditor-5
- Pillow (для работы с изображениями)

### Установка
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Выполнить миграции: `python manage.py migrate`
4. Создать суперпользователя: `python manage.py createsuperuser`
5. Запустить сервер: `python manage.py runserver`

### Настройка
1. В админке создать настройки сайта
2. Создать необходимые страницы
3. Настроить меню через флаги `show_in_menu`
4. Добавить файлы для управления через интерфейс

## Использование

### Административная панель
1. **Настройки сайта**: `/admin/main/sitesettings/`
   - Заполнить контактную информацию

## Устранение неполадок

### Ошибка циклического импорта
**Проблема**: `NameError: name 'ManagedFile' is not defined`
**Решение**: Убедиться, что все импорты выполнены корректно и нет дублирования кода.

### Файлы не отображаются
**Проблема**: Файлы существуют на диске, но не отображаются в админке
**Решение**: Использовать действие "Сканировать директории" или проверить права доступа.

### Ошибки кэширования
**Проблема**: Изменения не отображаются сразу
**Решение**: Очистить кэш Django или увеличить частоту обновления кэша.
