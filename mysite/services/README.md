# 🛠 Приложение Services (Услуги)

Каталог услуг компании с гибкой настройкой ценообразования.

## 📋 Возможности

*   **Каталог услуг**: Структурированный список предоставляемых услуг.
*   **Категории**: Группировка услуг по направлениям.
*   **Гибкое ценообразование**:
    *   Фиксированная цена.
    *   "От ..."
    *   "До ..."
    *   Диапазон "От ... до ..."
*   **Мультивалютность**: Поддержка RUB, USD, EUR, KZT.
*   **Маркетинговые инструменты**: Иконки, фоновые изображения, Hero-секции.

## 🗄 Модели

### `ServiceCategory` (Категория услуг)
*   Разделы каталога.
*   Настройки SEO и отображения в меню.

### `Service` (Услуга)
*   Детальное описание услуги (Short/Full description).
*   Цены (`price_fixed`, `price_from`, `price_to`).
*   Флаги: `can_order` (Можно заказать), `is_displayed`.
*   Счетчик просмотров.

## 🔗 Особенности
*   Каждая услуга имеет собственный URL (slug).
*   Поддержка форматированного вывода цен (`get_price_display`).
