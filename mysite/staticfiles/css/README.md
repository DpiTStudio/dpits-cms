# Структура CSS файлов проекта

## Описание

Все CSS стили проекта организованы в отдельные файлы по функциональному назначению. Каждый файл содержит подробные комментарии на русском языке, описывающие каждую строку кода.

## Порядок подключения файлов

Файлы должны подключаться в следующем порядке (уже настроено в `base.html`):

1. **variables.css** - CSS переменные (должен быть первым)
2. **base.css** - Базовые стили для всего сайта
3. **animations.css** - Глобальные анимации (появление, переходы)
4. **layout.css** - Стили макета (header, footer, навигация)
5. **components.css** - Компоненты интерфейса (карточки, кнопки, формы)
6. **hero.css** - Стили для hero секции
7. **sidebar.css** - Стили для боковой панели
8. **content.css** - Стили для основного контента
9. **utilities.css** - Утилитарные классы
10. **responsive.css** - Адаптивные стили (должен быть последним)

## Описание файлов

### variables.css
Содержит все CSS переменные проекта:
- Цвета (основные, состояния, текст)
- Градиенты
- Радиусы скругления
- Тени
- Переходы и анимации
- Отступы
- Размеры шрифтов
- Веса шрифтов
- Высота строк
- Z-index слои

### base.css
Базовые стили для всего сайта:
- Сброс стилей
- Настройки body и html
- Стили для основных элементов (ссылки, заголовки, параграфы, изображения)
- Настройки скроллбара

### animations.css
Файл с глобальными анимациями для улучшения пользовательского опыта (UX):
- `@keyframes fadeIn`: Плавное появление элементов.
- `@keyframes slideUp`: Появление элемента со сдвигом вверх.
- `@keyframes scaleIn`: Появление с эффектом увеличения.
- `.animate-fade-in`: Класс утилита для применения анимации появления.
- `.ripple`: Эффект волны для кнопок.
- Анимации для карточек (поднятие и тень при наведении).
- Поддержка `prefers-reduced-motion` для отключения анимаций по требованию системы пользователя.

### layout.css
Стили для основных элементов макета:
- Header (шапка сайта)
- Навигация
- Footer (подвал сайта)
- Выпадающие меню

### components.css
Стили для компонентов интерфейса:
- Карточки (базовые, новости, категории)
- Кнопки (различные варианты)
- Формы (поля ввода, метки)
- Бейджи
- Алерты

### hero.css
Стили для hero секции (главный баннер):
- Основная секция
- Заголовки и текст
- Изображения и логотипы
- Адаптивные стили

### sidebar.css
Стили для боковой панели:
- Карточки сайдбара
- Ссылки и элементы списка
- Изображения
- Контактная информация
- Адаптивные стили

### content.css
Стили для основного контента:
- Статьи и текст
- Секция преимуществ
- Контактная информация
- Хлебные крошки
- Адаптивные стили

### utilities.css
Утилитарные классы для быстрого применения:
- Цвета текста и фона
- Тени
- Скругление углов
- Отступы
- Текст (выравнивание, вес шрифта)
- Позиционирование
- Переходы
- Эффекты наведения
- Отображение
- Flexbox утилиты

### responsive.css
Адаптивные стили для всех устройств:
- Мобильные устройства (до 575.98px)
- Планшеты (576px - 767.98px)
- Ноутбуки (768px - 991.98px)
- Большие экраны (от 992px)
- Исправления для карточек, таблиц, форм, кнопок, изображений, модальных окон

## Использование

Все стили используют CSS переменные из `variables.css`, что позволяет легко изменять цветовую схему и другие параметры сайта, редактируя только один файл.

## Комментарии

Каждый CSS файл содержит подробные комментарии на русском языке, объясняющие назначение каждого стиля и свойства.
