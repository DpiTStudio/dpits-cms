# 📩 Приложение Feedback (Обратная связь)

Система обработки входящих сообщений с форм обратной связи на сайте.

## 📋 Возможности

*   **Сбор сообщений**: Хранение всех запросов с контактных форм в базе данных.
*   **Статусы обработки**: Новое, Прочитано, Отвечено, Архив.
*   **Email уведомления**: Флаг отправки уведомлений.
*   **Администрирование**: Поля для заметок администратора.

## 🗄 Модели

### `FeedbackMessage`
*   Привязка к пользователю (если авторизован).
*   Поля: Тема, Сообщение, Email для ответа.
*   Статусная модель для workflow обработки заявок.
*   Админские заметки (`admin_notes`).
