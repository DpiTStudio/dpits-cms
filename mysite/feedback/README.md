# Приложение "Обратная связь" (Feedback)

## Описание

Приложение для обработки обратной связи от зарегистрированных пользователей с отправкой уведомлений на email администратору.

## Функциональность

- ✅ Отправка сообщений обратной связи только зарегистрированными пользователями
- ✅ Защита от спама с помощью капчи (django-simple-captcha)
- ✅ Автоматическая отправка email администратору при получении нового сообщения
- ✅ Административный интерфейс для управления сообщениями
- ✅ Просмотр истории сообщений пользователем
- ✅ Статусы сообщений (новое, прочитано, отвечено, архивировано)

## Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Применение миграций

```bash
python manage.py makemigrations feedback
python manage.py migrate
```

### 3. Настройка email (опционально)

В файле `mysite/settings.py` раскомментируйте и настройте параметры SMTP:

```python
EMAIL_BACKEND = "django.core.mail.backends.smtp.EmailBackend"
EMAIL_HOST = "smtp.yandex.ru"
EMAIL_PORT = 587
EMAIL_USE_TLS = True
EMAIL_HOST_USER = "noreply@yourdomain.com"
EMAIL_HOST_PASSWORD = "your_password"
DEFAULT_FROM_EMAIL = "noreply@yourdomain.com"
```

Для разработки используется консольный бэкенд (письма выводятся в консоль).

### 4. Создание суперпользователя (если еще не создан)

```bash
python manage.py createsuperuser
```

## Использование

### Для пользователей

1. Войдите в систему (требуется регистрация)
2. Перейдите на страницу `/feedback/create/` для создания нового сообщения
3. Заполните форму:
   - Тема сообщения
   - Email для ответа
   - Текст сообщения
   - Капча (защита от спама)
4. Просматривайте свои сообщения на странице `/feedback/`

### Для администраторов

1. Войдите в админ-панель `/admin/`
2. Перейдите в раздел "Обратная связь" → "Сообщения обратной связи"
3. Управляйте сообщениями:
   - Просматривайте новые сообщения
   - Меняйте статусы
   - Добавляйте заметки
   - Отвечайте пользователям

## URL маршруты

- `/feedback/` - список сообщений пользователя
- `/feedback/create/` - создание нового сообщения
- `/feedback/<id>/` - детальный просмотр сообщения

## Модели

### FeedbackMessage

- `user` - пользователь, отправивший сообщение
- `subject` - тема сообщения
- `message` - текст сообщения
- `email` - email для ответа
- `status` - статус сообщения (new, read, replied, archived)
- `admin_notes` - заметки администратора
- `email_sent` - флаг отправки email
- `created_at` - дата создания
- `updated_at` - дата обновления

## Настройки капчи

Настройки капчи находятся в `mysite/settings.py`:

```python
CAPTCHA_LENGTH = 4  # Длина капчи
CAPTCHA_TIMEOUT = 5  # Время жизни в минутах
CAPTCHA_FONT_SIZE = 40  # Размер шрифта
CAPTCHA_IMAGE_SIZE = (120, 50)  # Размер изображения
```

## Примечания

- Все комментарии и строки в коде на русском языке
- Доступ к созданию сообщений только для зарегистрированных пользователей
- Email отправляется администратору автоматически при создании сообщения
- Email администратора определяется в следующем порядке:
  1. `ADMIN_EMAIL` в settings.py
  2. Email из `SiteSettings`
  3. Email первого суперпользователя
