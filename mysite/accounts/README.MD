# Приложение Accounts (Управление пользователями)

Данное приложение отвечает за управление учетными записями пользователей, расширенными профилями и системой технической поддержки (тикетов) в рамках DPITS-CMS.

## Состав файлов и их назначение

### Основные файлы логики

- **`models.py`**: Содержит модели данных:
  - `UserProfile`: Расширенный профиль (телефон, аватар, биография, дата создания).
  - `Ticket`: Система обращений (тема, статус, приоритет, автор).
  - `TicketResponse`: Ответы на обращения от пользователей и администрации.
- **`views.py`**: Обработка запросов (регистрация, вход/выход, редактирование профиля, управление тикетами).
- **`forms.py`**: Формы для взаимодействия с пользователем (регистрация с капчей, обновление данных, создание тикетов).
- **`urls.py`**: Конфигурация маршрутов для всех страниц личного кабинета и аутентификации.

### Инфраструктурные файлы

- **`admin.py`**: Настройка отображения моделей в административной панели Django.
- **`apps.py`**: Техническая конфигурация приложения Django.
- **`signals.py`**: Автоматическое создание профиля `UserProfile` при регистрации нового пользователя.
- **`backends.py`**: Кастомный бэкенд `EmailOrUsernameModelBackend`, позволяющий входить на сайт как по логину, так и по email.
- **`context_processors.py`**: Глобальный доступ к базовым настройкам (Site Name, Support Email) во всех шаблонах.
- **`utils.py`**: Вспомогательные функции (сбор статистики пользователя, универсальный обработчик форм).
- **`mixins.py`**: Миксины для контроллеров (например, проверка прав доступа к тикету).

## Основные функции и классы

### Модели (models.py)

- **`UserProfile`**:
  - `get_avatar_url()`: Возвращает URL аватара или стандартное изображение заглушку.
  - `clean()`: Валидация формата номера телефона.
- **`Ticket`**:
  - `is_open() / is_closed()`: Проверка текущего статуса.
  - `can_user_access(user)`: Проверка прав доступа (автор или сотрудник).
- **`TicketResponse`**: Хранит историю переписки по проблеме.

### Представления (views.py)

- **`register(request)`**: Регистрация с проверкой капчи.
- **`profile_view(request)`**: Главная страница личного кабинета со статистикой.
- **`profile_update(request)`**: Редактирование расширенных данных профиля (аватар, телефон).
- **`password_change(request)`**: Смена пароля без разлогинивания.
- **`ticket_list` / `ticket_detail` / `create_ticket`**: Полный цикл работы с техподдержкой.
- **`custom_logout`**: Безопасный выход из системы через POST-запрос.

### Формы (forms.py)

- **`UserRegisterForm`**: Валидация уникальности email, совпадения паролей и капчи.
- **`CustomAuthenticationForm`**: Вход в систему с защитой от ботов.

## Настройки и конфигурация

Приложение использует следующие настройки из `settings.py`:

### Аутентификация

- `LOGIN_REDIRECT_URL = "accounts:profile"`: Куда направлять после входа.
- `LOGOUT_REDIRECT_URL = "main:index"`: Куда направлять после выхода.
- `LOGIN_URL = "accounts:login"`: Путь к странице входа.
- `AUTHENTICATION_BACKENDS`: Должен включать `accounts.backends.EmailOrUsernameModelBackend`.

### Капча (django-simple-captcha)

- `CAPTCHA_LENGTH = 3`: Количество символов.
- `CAPTCHA_TIMEOUT = 10`: Время жизни в минутах.
- `CAPTCHA_FONT_SIZE = 40`: Размер шрифта.

### Директории

- `MEDIA_ROOT` и `MEDIA_URL`: Используются для хранения и отображения аватаров пользователей (путь `avatars/%Y/%m/%d/`).

## Использование в шаблонах

Для доступа к профилю текущего пользователя в любом шаблоне используйте:

```html
{{ user.profile.get_avatar_url }}  <!-- URL аватара -->
{{ user.profile.phone }}           <!-- Номер телефона -->
```

Для вывода системных настроек (через context_processor):

```html
{{ site_settings.logo_text }}
{{ site_settings.support_email }}
```
