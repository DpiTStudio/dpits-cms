# Документация приложения accounts

Приложение `accounts` отвечает за управление пользователями, их профилями и системой тикетов поддержки.

## 2. Обзор

Ключевые возможности:
- Регистрация и авторизация пользователей
- Профили с возможностью редактирования
- История заказов и взаимодействий
- Тикет‑система для обращения в поддержку

## 3. Описание файлов

### `admin.py`
- Регистрация моделей `User`, `Profile`, `Ticket`
- Настройки отображения в админке (list_display, list_filter, search_fields)
- Кастомные действия для массовой обработки тикетов

### `apps.py`
- Конфигурация приложения `AccountsConfig`
- Verbose name: "Аккаунты"

### `models.py`
- Модель `User` (наследует `AbstractUser`)
- Модель `Profile` с полями `avatar`, `bio`, `phone`
- Модель `Ticket` с полями `subject`, `status`, `created_at`

### `forms.py`
- `UserCreationForm`, `UserChangeForm`
- `ProfileForm` и `TicketForm` с кастомными виджетами

### `views.py`
- Представления для регистрации, входа, выхода
- Профиль пользователя, редактирование
- Управление тикетами (создание, список, детализация)

### `urls.py`
- Маршруты: `/register/`, `/login/`, `/profile/`, `/tickets/`

### `templates/`
- Шаблоны `register.html`, `login.html`, `profile.html`, `ticket_list.html`

## 4. Особенности реализации
- Использование кастомного `User` модели
- Интеграция с `django-simple-captcha` для защиты форм
- Сигналы для автоматического создания профиля при регистрации пользователя
