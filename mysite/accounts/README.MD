# 👤 Приложение Accounts (Аккаунты)

Управление пользователями, расширенными профилями и системой технической поддержки (тикетами).

## 🚀 Функционал

*   **Расширенный профиль**: Дополнительные данные о пользователе (аватар, телефон, биография).
*   **Тикет-система**: Полноценная система поддержки пользователей.
    *   Создание тикетов.
    *   Статусы (Открыт, В обработке, Закрыт).
    *   Переписка внутри тикета.
*   **Аватар**: Загрузка пользовательских аватаров с валидацией.

## 🗄 Модели

### `UserProfile`
*   Связь One-to-One с моделью `User`.
*   Хранит телефон, аватар, био.
*   Автоматическое создание при регистрации пользователя (Signal `post_save`).

### `Ticket`
*   Обращение в техподдержку.
*   Тема, сообщение, статус.
*   Индексация для быстрого поиска.

### `TicketResponse`
*   Ответы в тикетах.
*   Флаг `is_admin_response` для выделения ответов сотрудников.

## 🔐 Безопасность
*   Валидация телефонов.
*   Проверка прав доступа к тикетам (только автор или персонал).
