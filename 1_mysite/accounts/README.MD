# Приложение Accounts (Учетные записи)

Django приложение для управления пользователями, профилями и системой тикетов поддержки.

## Структура файлов

### Модели
- **models.py** - Модели данных приложения
  - `UserProfile` - Расширенный профиль пользователя
  - `Ticket` - Тикеты технической поддержки
  - `TicketResponse` - Ответы на тикеты

### Формы
- **forms.py** - Формы для регистрации, редактирования профиля и тикетов
  - `UserRegisterForm` - Регистрация нового пользователя
  - `UserUpdateForm` - Обновление данных пользователя
  - `ProfileUpdateForm` - Обновление профиля
  - `TicketForm` - Создание тикета
  - `TicketResponseForm` - Ответ на тикет

### Представления
- **views.py** - Обработчики запросов
  - Аутентификация (регистрация, вход, выход)
  - Управление профилем
  - Работа с тикетами

### URL-адреса
- **urls.py** - Маршрутизация приложения

### Админ-панель
- **admin.py** - Настройки административного интерфейса

### Сигналы
- **signals.py** - Обработчики сигналов для автоматического создания профилей

### Утилиты
- **utils.py** - Вспомогательные функции и утилиты

### Контекстные процессоры
- **context_processors.py** - Добавление настроек сайта в контекст шаблонов

### Бэкенды аутентификации
- **backends.py** - Кастомная аутентификация по email/username

### Миксины
- **mixins.py** - Миксины для проверки прав доступа

## Основные функции

### Управление пользователями
- Регистрация новых пользователей
- Аутентификация (вход/выход)
- Редактирование профиля
- Смена пароля

### Система тикетов
- Создание тикетов поддержки
- Ответы на тикеты
- Отслеживание статусов
- Разделение прав доступа (пользователь/администратор)

### Профили пользователей
- Расширенные данные (телефон, аватар, биография)
- Автоматическое создание профилей
- Валидация данных

## Установка и настройка

1. Добавьте `'accounts'` в `INSTALLED_APPS`
2. Подключите URLs в главном `urls.py`
3. Выполните миграции
4. Настройте статические файлы и медиа

## Особенности

- Полная интеграция с Django Auth
- Оптимизированные запросы к БД
- Подробное логирование ошибок
- Responsive дизайн шаблонов
- Валидация данных на стороне клиента и сервера
- Поддержка перевода (i18n)
