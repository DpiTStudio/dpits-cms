# DPITS-CMS (DpiTStudio CMS)

Комплексная система управления контентом на базе Django, разработанная для создания многофункциональных сайтов с новостями, портфолио, личными кабинетами клиентов, тикет-системой и гибкой админ-панелью.

## 🚀 Основные возможности

- **Управление контентом**: Динамические страницы, новости и категории.
- **Портфолио и Заказы**: Демонстрация работ, управление клиентами и заказами через личный кабинет.
- **Аккаунты и Поддержка**: Регистрация пользователей, расширенные профили и тикет-система для техподдержки.
- **Обратная связь и Отзывы**: Формы обратной связи с защитой от спама (Captcha) и система модерации отзывов.
- **Продвинутая Админка**: Интеграция с Jazzmin для современного интерфейса и CKEditor 5 для удобного редактирования контента.
- **Управление Файлами**: Резервное копирование и редактирование критических файлов проекта прямо из админки.
- **Мониторинг**: Встроенная система анализа логов и статистики сайта.

## 🛠 Технологический стек

- **Backend**: Python 3.11+, Django 5.2.6
- **Database**: SQLite (разработка), поддержка PostgreSQL/MySQL
- **Frontend**: HTML5, CSS3 (Modern Vanilla CSS), Vanilla JavaScript
- **UI Frameworks**: Jazzmin (Admin Panel)
- **Editor**: CKEditor 5
- **Security**: Django Simple Captcha, Django Security Middleware
- **Performance**: Django Caching (Redis support), select_related/prefetch_related optimizations
- **Deployment**: Поддержка Passenger (для хостингов типа Beget), WSGI/ASGI

## 📁 Структура проекта

Проект организован по модульному принципу, где за каждый аспект функциональности отвечает отдельное приложение:

### ⚙️ Main (Ядро системы)
Центральный модуль управления сайтом.
- **Страницы (CMS)**: Создание и редактирование динамических страниц с SEO-настройками.
- **Глобальные настройки**: Управление логотипом, контактами, социальными сетями и режимом тех. обслуживания через админку.
- **Файловый менеджер**: Встроенный инструмент для просмотра логов, редактирования шаблонов и управления бэкапами файлов.
- **Hero-секции**: Универсальный механизм настройки заголовков и баннеров для всех разделов сайта.

### 📰 News (Новости)
Полноценный новостной движок.
- **Категоризация**: Группировка новостей по рубрикам.
- **SEO**: Автоматическая генерация мета-тегов.
- **Интеграция**: Возможность создания новостей на основе событий портфолио.

### 🎨 Portfolio (Портфолио и CRM)
Комплексное решение для демонстрации работ и работы с клиентами.
- **Проекты**: Детальное описание кейсов с указанием технологий и ссылок.
- **Клиенты**: База данных заказчиков.
- **Заказы (CRM)**: Внутренняя система трекинга заказов (статусы, бюджеты, дедлайны).
- **Отзывы к работам**: Сбор обратной связи по конкретным проектам.

### 🛠 Services (Услуги)
Каталог предоставляемых услуг.
- **Цены**: Поддержка фиксированных цен, диапазонов ("от", "до") и разных валют.
- **Оформление**: Индивидуальные иконки и фоны для каждой услуги.
- **Заказ**: Возможность быстрой отправки заявки на услугу.

### 👤 Accounts (Пользователи)
Расширенная система профилей.
- **Личный кабинет**: Управление аватаром, данными и биографией.
- **Тикет-система**: Встроенная служба поддержки с трекингом статусов обращений.

### 📩 Feedback (Обратная связь)
Центр обработки входящих сообщений.
- **Агрегация**: Сбор всех заявок с контактных форм.
- **Статусы**: Workflow обработки сообщений (Новое -> В работе -> Архив).

### ⭐ Reviews (Отзывы о сайте)
Система сбора мнений/отзывов.
- **Модерация**: Премодерация всех входящих отзывов перед публикацией.

### 📦 Config (Mysite)
- Корневые настройки Django (`settings.py`), маршрутизация (`urls.py`) и конфигурация WSGI/ASGI.

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url_репозитория>
   cd dpits-cms
   ```

2. **Создайте и активируйте виртуальное окружение**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/macOS
   .venv\Scripts\activate     # Для Windows
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r mysite/requirements.txt
   ```

4. **Примените миграции**:
   ```bash
   cd mysite
   python manage.py migrate
   ```

5. **Создайте суперпользователя**:
   ```bash
   python manage.py createsuperuser
   ```

6. **Запустите сервер разработки**:
   ```bash
   python manage.py runserver
   ```
   Сайт будет доступен по адресу: `http://127.0.0.1:8000/`

## 📦 Развертывание (Beget/Passenger)

Для развертывания на хостинге Beget используйте файл `passenger_wsgi.py` и убедитесь, что конфигурация в `mysite/settings.py` соответствует продакшн-окружению (`DEBUG = False`, `ALLOWED_HOSTS`, `STATIC_ROOT`).

Для перезапуска приложения на хостинге:
```bash
touch mysite/mysite/tmp/restart.txt
```

## 📊 Мониторинг и Логи

Логи хранятся в директории `mysite/logs/`.
Администраторы могут просматривать статистику логов по адресу `/log-stats/` или через специальный раздел в панели управления.
