# DPITS-CMS (DpiTStudio CMS)

Комплексная система управления контентом на базе фреймворка Django. Система разработана для создания многофункциональных и высокопроизводительных веб-сайтов, предлагая готовые решения для новостных порталов, корпоративных сайтов с портфолио, личных кабинетов клиентов, встроенной тикет-системы и максимально гибкой административной панели.

## 🚀 Основные возможности

- **Динамическое управление контентом (CMS)**: Создание, редактирование и публикация пользовательских страниц, новостей, рубрик и категорий "на лету" с поддержкой SEO-мета-тегов и ЧПУ (человеко-понятных URL).
- **Развитое портфолио и управление заказами**: Подробная демонстрация выполненных работ (кейсов), интеграция с базой клиентов, а также управление заказами и этапами работы через защищенный личный кабинет.
- **Полноценные аккаунты пользователей и поддержка**: Регистрация, авторизация пользователей, расширенные профили с возможностью редактирования данных и встроенная тикет-система для оперативной технической поддержки.
- **Безопасная обратная связь и отзывы**: Формы обратной связи и сбора мнений, оснащенные надежной защитой от спам-ботов (интеграция Captcha), а также система премодерации пользовательских отзывов перед публикацией.
- **Продвинутая и удобная Админ-панель**: Интеграция с библиотекой Jazzmin для создания современного, адаптивного и кастомизируемого интерфейса администратора, плюс встроенный визуальный редактор CKEditor 5 для комфортной работы с текстом и медиа-контентом.
- **Файловый менеджер и безопасность**: Встроенные инструменты для резервного копирования баз данных, прямого редактирования шаблонов и конфигурационных файлов из панели управления.
- **Мониторинг и аналитика**: Продвинутая система агрегации и анализа лог-файлов, отслеживание ошибок, посещаемости и общей статистики работы сайта в режиме реального времени.

## 🛠 Технологический стек

- **Backend (Серверная часть)**: Python 3.11+, Django 5.2.6 (или выше)
- **Database (Базы данных)**: SQLite 3 (для локальной разработки), полная поддержка PostgreSQL и MySQL для продакшена
- **Frontend (Клиентская часть)**: HTML5, CSS3 (современный Vanilla CSS с CSS-переменными), Vanilla JavaScript (без перегрузки тяжелыми фреймворками)
- **UI Frameworks**: Jazzmin (для стилизации Django Admin Panel)
- **Rich Text Editor**: CKEditor 5 (для форматирования контента)
- **Security (Безопасность)**: Django Simple Captcha, Django Security Middleware, защита от CSRF/XSS/SQL-инъекций
- **Performance (Производительность)**: Django Caching Framework (с поддержкой Redis/Memcached), оптимизация ORM-запросов (`select_related`, `prefetch_related`)
- **Deployment (Развертывание)**: Поддержка Passenger (идеально для виртуальных хостингов, таких как Beget), полная совместимость со стандартами WSGI и ASGI (для асинхронных задач)

## 📁 Структура проекта и архитектура приложений

Проект организован по строгому модульному принципу. Каждый аспект бизнес-логики и функциональности изолирован в отдельном приложении Django, что обеспечивает высокую масштабируемость и простоту поддержки:

### ⚙️ Main (Ядро системы - `main`)
Центральный инфраструктурный модуль, управляющий общим поведением сайта.
- **Динамические страницы**: Создание страниц "О нас", "Контакты" и др. с индивидуальными SEO-настройками (Title, Description).
- **Глобальная конфигурация**: Управление логотипами сайта, контактными данными (телефон, email, адреса), ссылками на социальные сети и включение/выключение режима технического обслуживания прямо из админки.
- **Файловый менеджер**: Встроенный безопасный инструмент для просмотра лог-файлов, быстрого редактирования HTML-шаблонов и управления резервными копиями проекта.
- **Система Hero-секций**: Универсальный и гибкий механизм для создания и настройки главных баннеров (Hero Headers) для любых разделов и страниц сайта.

### 📰 News (Новостной движок - `news`)
Полноценный модуль для ведения блога или новостной ленты.
- **Многоуровневая категоризация**: Группировка статей по рубрикам и тегам для удобной навигации.
- **SEO-оптимизация**: Автоматическая и ручная генерация мета-тегов, создание Open Graph разметки.
- **Событийная интеграция**: Возможность автоматического создания новостных публикаций на основе завершенных проектов из модуля портфолио.
- **Отложенная публикация**: Система черновиков и публикация материалов по заданному расписанию.

### 🎨 Portfolio (Портфолио и CRM - `portfolio`)
Комплексное решение для студий и фрилансеров: демонстрация работ и ведение клиентов.
- **Управление проектами (Кейсы)**: Детальное описание выполненных работ, галерея изображений, стек использованных технологий и ссылки на результат.
- **База клиентов**: Хранение информации о заказчиках и истории взаимодействия.
- **Внутренняя CRM (Заказы)**: Трекинг текущих и завершенных заказов, управление статусами, учет бюджетов и контроль дедлайнов.
- **Проектные отзывы**: Сбор и публикация обратной связи, привязанной к конкретным выполненным проектам.

### 🛠 Services (Каталог услуг - `services`)
Модуль для презентации предоставляемых услуг.
- **Гибкое ценообразование**: Поддержка точных фиксированных цен, ценовых диапазонов (например, "от 1000 до 5000") и мультивалютности.
- **Визуальное оформление**: Настройка индивидуальных иконок, SVG-графики и фоновых изображений для каждой услуги.
- **Система заявок**: Формы быстрого заказа или запроса консультации, привязанные к конкретной услуге.

### 👤 Accounts (Пользователи и профили - `accounts`)
Расширенная система аутентификации и профилирования.
- **Личный кабинет клиента**: Защищенная зона для пользователей, управление личными данными, смена аватаров и редактирование биографии.
- **История взаимодействия**: Просмотр пользователем своих заказов и статусов их выполнения.
- **Тикет-система (Helpdesk)**: Встроенная многопользовательская служба поддержки с возможностью создания обращений, общения с администрацией и трекингом статусов решения проблем.

### 📩 Feedback (Обратная связь - `feedback` / `mail`)
Централизованный узел обработки входящих обращений с сайта.
- **Агрегация запросов**: Единый центр сбора заявок со всех контактных форм, виджетов и форм заказа услуг.
- **Workflow обработки**: Удобное управление статусами сообщений (Новое -> Взято в работу -> Решено -> В архиве).
- **Уведомления**: Отправка email-оповещений администраторам о новых заявках.

### ⭐ Reviews (Отзывы о сайте - `reviews`)
Модуль для сбора и демонстрации публичных мнений о компании или сайте.
- **Премодерация**: Защита от спама и нежелательного контента — все новые отзывы скрыты по умолчанию и требуют одобрения администратора.
- **Рейтинговая система**: Оценка качества услуг по 5-звездочной шкале.

### 📦 Config (Настройки проекта - `mysite`)
- Корневые настройки фреймворка Django (`settings.py`), главная маршрутизация URL-адресов (`urls.py`) и конфигурационные файлы для серверов приложения (WSGI/ASGI).

## ⚙️ Пошаговая установка и локальный запуск

Следуйте этим шагам для развертывания проекта на локальном компьютере для разработки или тестирования.

1. **Клонируйте репозиторий проекта**:
   ```bash
   git clone <url_репозитория>
   cd dpits-cms
   ```

2. **Создайте и активируйте изолированное виртуальное окружение**:
   Это необходимо для избежания конфликтов версий библиотек.
   ```bash
   python -m venv .venv
   
   # Для операционных систем Linux / macOS:
   source .venv/bin/activate
   
   # Для операционных систем Windows (Командная строка / PowerShell):
   .venv\Scripts\activate
   ```

3. **Установите все необходимые зависимости**:
   Убедитесь, что ваш `pip` обновлен, и установите пакеты из файла требований.
   ```bash
   python -m pip install --upgrade pip
   pip install -r mysite/requirements.txt
   ```

4. **Примените миграции базы данных**:
   Это создаст структуру таблиц в вашей локальной базе данных (по умолчанию SQLite).
   ```bash
   cd mysite
   python manage.py makemigrations
   python manage.py migrate
   ```

5. **Создайте учетную запись суперпользователя (Администратора)**:
   Следуйте инструкциям в консоли (введите логин, email и пароль).
   ```bash
   python manage.py createsuperuser
   ```

6. **Сборка статических файлов (опционально для локальной разработки, обязательно для продакшена)**:
   ```bash
   python manage.py collectstatic
   ```

7. **Запустите локальный сервер разработки**:
   ```bash
   python manage.py runserver
   ```
   После этого сайт будет доступен в вашем браузере по адресу: `http://127.0.0.1:8000/`
   Админ-панель доступна по адресу: `http://127.0.0.1:8000/admin/`

## 📦 Развертывание в Production (на примере хостинга Beget / Passenger)

Система полностью готова к деплою на виртуальные хостинги с поддержкой Python (Passenger).

1. Перенесите файлы проекта на хостинг.
2. Настройте виртуальное окружение на сервере и установите зависимости (`pip install -r requirements.txt`).
3. В файле `mysite/settings.py` (или через переменные окружения `.env`) обязательно установите:
   - `DEBUG = False`
   - `ALLOWED_HOSTS = ['ваш_домен.ru', 'www.ваш_домен.ru']`
   - Настройте параметры базы данных (PostgreSQL/MySQL), если не используете SQLite.
4. Выполните миграции и соберите статику на сервере:
   ```bash
   python manage.py migrate
   python manage.py collectstatic
   ```
5. Убедитесь, что корневой файл `passenger_wsgi.py` корректно ссылается на ваше WSGI-приложение.
6. **Для перезапуска приложения на хостинге** после внесения изменений в код, используйте команду (обновление timestamp файла `restart.txt`):
   ```bash
   touch mysite/mysite/tmp/restart.txt
   ```

## 📊 Мониторинг, Логирование и Безопасность

Система обладает встроенными механизмами для обеспечения стабильности и безопасности:
- **Хранение логов**: Все системные логи, ошибки и предупреждения бережно сохраняются в директории `mysite/logs/`.
- **Просмотр статистики**: Администраторы имеют доступ к удобному интерфейсу просмотра статистики логов по внутреннему маршруту `/log-stats/` или через специализированный дашборд в панели управления Jazzmin.
- **Резервное копирование**: Рекомендуется регулярно использовать встроенный функционал создания бэкапов через панель администратора для предотвращения потери данных.
