# Улучшения сайта DPITS-CMS

## 📋 Обзор улучшений

Сайт был значительно улучшен с точки зрения функциональности и визуального дизайна. Ниже перечислены все реализованные улучшения.

## ✨ Реализованные функции

### 1. 🌓 Темная тема (Dark Mode)
- **Файлы**: `dark-mode.css`, `theme-toggle.js`
- **Функционал**:
  - Переключатель темы в шапке сайта
  - Автоматическое определение системных настроек
  - Сохранение выбранной темы в localStorage
  - Полная поддержка всех компонентов сайта
  - Плавные переходы между темами

### 2. 📊 Индикатор прогресса чтения
- **Файлы**: `reading-progress.css`, `reading-progress.js`
- **Функционал**:
  - Визуальный индикатор вверху страницы
  - Показывает процент прочитанного контента
  - Градиентная анимация
  - Автоматическое обновление при прокрутке

### 3. 🔍 Поиск по сайту
- **Файлы**: `search.css`, `search.js`
- **Функционал**:
  - Поиск в шапке сайта
  - Автодополнение результатов
  - Поиск по новостям, портфолио и другим разделам
  - Красивое выпадающее меню с результатами
  - Debounce для оптимизации запросов

### 4. 🍞 Хлебные крошки (Breadcrumbs)

- **Функционал**:

  - Легко интегрируется в любой шаблон

### 5. 📱 Социальный шаринг

## 🚀 Как использовать

### Темная тема
Переключатель темы автоматически появляется в шапке сайта. Тема сохраняется в браузере пользователя.

### Поиск
Поле поиска доступно в шапке сайта (скрыто на мобильных). Начните вводить текст для получения результатов.

### Хлебные крошки
Добавьте в шаблон:
```django
{% include 'breadcrumbs.html' %}
```

### Социальный шаринг
Добавьте в шаблон:
```django
{% include 'social-share.html' %}
```

### Ленивая загрузка изображений
Используйте атрибут `data-src` вместо `src`:
```html
<img data-src="/path/to/image.jpg" alt="Описание" class="lazy-image">
```
