# Унификация заголовков страниц

## Описание изменений

Все основные страницы приложений теперь имеют единообразный дизайн заголовков с использованием следующей структуры:

```html
<div class="row mb-5 text-left">
    <div class="col-lg-8 mx-auto">
        <span class="badge text-primary bg-primary-subtle rounded-pill px-3 py-1 mb-2 fw-bold">НАЗВАНИЕ РАЗДЕЛА</span>
        <h1 class="display-4 fw-bold mb-3">Заголовок страницы</h1>
        <p class="lead text-muted">Описание страницы и ее назначения.</p>
    </div>
</div>
```

## Обновленные страницы

### 1. **Приложение News (Новости)**

#### `news/list.html`
- **Значок**: НОВОСТИ
- **Заголовок**: Актуальные события
- **Описание**: Следите за последними новостями и обновлениями из мира технологий и разработки.

#### `news/category.html`
- **Значок**: КАТЕГОРИЯ НОВОСТЕЙ
- **Заголовок**: {{ category.name }} (динамический)
- **Описание**: Все новости в категории или описание категории

#### `services/category.html`
- **Значок**: КАТЕГОРИЯ УСЛУГ
- **Заголовок**: {{ category.name }} (динамический)
- **Описание**: Все услуги в категории или описание категории

### 3. **Приложение Portfolio (Портфолио)**

## Преимущества единого стиля

1. **Консистентность**: Все страницы следуют единому визуальному паттерну
2. **Улучшенная навигация**: Пользователи сразу понимают, на какой странице находятся
3. **Профессиональный вид**: Унифицированный дизайн создает впечатление продуманной системы
4. **SEO-дружественность**: Структурированные заголовки H1 улучшают индексацию
5. **Адаптивность**: Все блоки корректно отображаются на мобильных устройствах

## Используемые Bootstrap классы

- `badge text-primary bg-primary-subtle rounded-pill` - стилизованный значок раздела
- `display-4 fw-bold` - крупный выразительный заголовок
- `lead text-muted` - большое описание серого цвета
- `col-lg-8 mx-auto` - центрирование контента с максимальной шириной

## Примечания

- Все описания можно легко изменить под конкретную тематику проекта
- Для категорий используются динамические заголовки с названием категории
- Сохранена обратная совместимость - удалены только дублирующие заголовки
